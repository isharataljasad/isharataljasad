# رحلة المعلم

منصة عربية للتخطيط لتطبيق صفي، وتوثيق الأدلة، والتأمل في النتائج، وتصدير بطاقة التطبيق والتقرير بصيغة Word.

## الاستخدام

1. اختر «ابدأ رحلتي» وأكمل المحطات الأربع.
2. نزّل بطاقة التطبيق، ثم عد بعد التنفيذ الفعلي لتوثيق التجربة.
3. راجع اكتمال إجاباتك، ثم حرّر التقرير ونزّل ملف Word.
4. نزّل نسخة احتياطية JSON قبل تغيير الجهاز أو حذف بيانات المتصفح. استعدها من «استعادة رحلة سابقة».

الإجابات محفوظة في localStorage على الجهاز والمتصفح نفسه. لا توجد حسابات للمعلمين أو مزامنة سحابية. لا تُرسل إجابات الرحلة لخدمات خارجية؛ توليد DOCX يتم محليًا في المتصفح. لا تدرج أسماء الطلاب أو معلومات تكشف هويتهم.

## حدود النسخة

- المراجعة استرشادية بقواعد واضحة وليست ذكاءً اصطناعيًا أو تقديرًا لجودة التأمل. لا تمنح درجات ولا تضمن مستوى في سلم التقدير.
- استُخدمت الأبعاد السبعة في ملف المشروع. مستند «مهمة التأمل» وأوصاف سلم التقدير الأصلي لم يكونا مرفقين، ولذلك تحتاج المطابقة التربوية النهائية إلى مراجعتهما عند توفيرهما.
- التقرير قالب من نصوص المعلم الأصلية، ويمكن تحريره يدويًا. تغيير الإجابات لا يستبدل التحرير اليدوي تلقائيًا.
- الأدلة نصية فقط؛ لا توجد وظيفة رفع صور.
- لا توجد لوحة إدارة أو دعوات تحرير للموقع من حسابات ChatGPT. تطوير الموقع يجري عبر مصدره البرمجي ومستودع GitHub المرتبط باستضافة Vercel.
- نقل الرحلة بين نطاقين أو متصفحين يحتاج إلى تنزيل النسخة الاحتياطية واستيرادها؛ التخزين المحلي مرتبط بأصل الموقع.

## التطوير

React وTypeScript وVite، مع docx لإنشاء ملفات Word حقيقية، وخط Tajawal مستضاف مع التطبيق.

```sh
npm ci
npm run dev
npm run build
npm test
```

`npm run build` ينشئ `dist/`. إعداد النشر في `vercel.json`. لا تُنشر ملفات `.env*` أو `.vercel/` أو `node_modules/`.

ملفات العمل الأساسية:

- `src/components/Stations.tsx`: أسئلة المحطات والبطاقات.
- `src/model.ts`: نموذج البيانات، تحقق النسخ الاحتياطية، مراجعة الاكتمال، وبناء نص التقرير.
- `src/export.ts`: توليد ملفات DOCX باتجاه عربي RTL.
- `src/App.tsx`: تنقل الرحلة والحفظ والمعاينة.
- `src/style.css`: الهوية والتصميم المتجاوب.

## التحقق

اختبارات النموذج تغطي رفض النسخ التالفة، والحفاظ على العربية والتحرير اليدوي، ومنع تجاوز إقرار التطبيق، واكتمال وصف الأدلة، وحدود المراجعة.

`tests/e2e.mjs` اختبار Playwright للرحلة كاملة والتنزيلات والاستعادة وحماية التقرير وعرض الجوال. يستخدم Chrome المثبت محليًا ومسار خادم محلي؛ عدّل مسار المتصفح عند تشغيله على نظام آخر. لا يتضمن التطبيق أمثلة الاختبار أو بيانات تجريبية محفوظة.

## التعاون في تطوير الموقع

يمكن للمالكة دعوة زميلتها إلى مستودع GitHub بصلاحية كتابة مناسبة. تعمل كل واحدة على فرع مستقل، وتُراجع التغييرات قبل دمجها إلى `main` الذي ينشره Vercel. صلاحيات GitHub وVercel مستقلة عن حسابات ChatGPT؛ لا تتم مشاركة كلمات المرور. لم تُضف أي دعوات تلقائيًا.

# Isharataljasad.com — Static Website

نسخة نشر جاهزة لموقع **إشارات الجسد | Bio-OS** بصيغة HTML/CSS/JS فقط.

## الملفات المضافة للنشر
- `site.webmanifest`
- `browserconfig.xml`
- `favicon.ico`
- `favicon.svg`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `apple-touch-icon.png`
- `android-chrome-192x192.png`
- `android-chrome-512x512.png`
- `mstile-150x150.png`
- `og-image.png`
- `sitemap.xml`
- `robots.txt`
- `.nojekyll`
- `vercel.json`

## النشر على GitHub Pages
1. ارفع جميع الملفات كما هي إلى المستودع.
2. فعّل Pages من إعدادات المستودع.
3. اربط الدومين: `https://www.isharataljasad.com`.
4. تأكد من وجود ملف `.nojekyll` في الجذر.

## النشر على Vercel
1. اربط المستودع مع Vercel.
2. لا تحتاج Build Command.
3. اجعل Output Directory = `/` أو اتركها فارغة.
4. أضف الدومين `https://www.isharataljasad.com` من إعدادات المشروع.

## ملاحظة تحريرية
الموقع عام وتثقيفي، ولا ينبغي تعديل النصوص بطريقة توحي بتشخيص فردي أو علاج أو متابعة علاجية عامة عبر الموقع.

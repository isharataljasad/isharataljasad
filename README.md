# موجّه حماية الكلى — إشارات الجسد | بوصلة الإشارات

موقع ثابت (Static) للموسم الأول: **«الكلى لا تنهار فجأة»**.
محتوى تثقيفي لتنظيم الأسئلة مع الطبيب — **ليس تشخيصًا ولا وصفًا علاجيًا ولا جرعات**.

## الفكرة (نظام وصول مجاني، بلا إعلانات مدفوعة)

- **المنشور** على وسائل التواصل = بوابة الجذب.
- **التعليق** بكلمة «الكلى» = قياس اهتمام.
- **الرسالة الخاصة** = تسليم الرابط والباسورد.
- **الموقع** = الأصل المملوك والبيت الحقيقي للمحتوى.

الباسورد ليس بيعًا ولا اشتراكًا، بل احترام للجهد وتنظيم للوصول، والموسم مجاني بالكامل.


## المواصفات

HTML/CSS/JS ثابت — بدون React وبدون أدوات بناء. عربي كامل `lang="ar" dir="rtl"`، متجاوب يبدأ من الجوال
(مقروء على 360px / 390px / 430px). الخطوط من Google Fonts (Tajawal + IBM Plex Sans Arabic) مع بدائل نظام،
وكل صفحة تحوي **CSS احتياطيًا داخليًا** يُبقيها مقروءة حتى لو فشل تحميل الملف الخارجي بعد النشر.
لا تُحفظ أي بيانات صحية من الزائر.

## النشر على Vercel

من اللوحة: **Add New → Project → اربط المستودع → Framework: Other**، بلا أمر بناء، Output: `./` → **Deploy**.
أو عبر الطرفية: `npm i -g vercel && vercel --prod`.

ملف `vercel.json` يفعّل **الروابط النظيفة** (`/episode-1` بدل `/episode-1.html`) ويمنع الشرطة الأخيرة.
تُقدَّم `404.html` تلقائيًا. الروابط الداخلية بصيغة `.html` تُعاد توجيهًا للنسخة النظيفة دون كسر.

## تغيير كلمة المرور

افتح `assets/js/main.js` وعدّل القيمة:

```js
var KIDNEY_SEASON_PASSWORD = 'KIDNEY2026';   // ← غيّرها هنا
```

الكلمة غير حساسة لحالة الأحرف (KIDNEY2026 = kidney2026). يُحفظ الوصول في `localStorage` فيبقى الموسم
مفتوحًا بين الزيارات، ويمكن إنهاؤه من زر **«إنهاء الوصول»** في صفحة الدخول.

### ⚠️ تنبيه أمني مهم

هذه **حماية ناعمة على مستوى النموذج الأولي فقط**: كلمة المرور مكتوبة داخل ملف JavaScript ويمكن لأي
شخص قراءتها من مصدر الصفحة. إنها مناسبة لتنظيم الوصول لا لحماية سرّ حقيقي. للحماية الجادة لاحقًا
استخدم **Password Protection في Vercel** أو نظام دخول حقيقي على الخادم.

عند تعطيل JavaScript لا تعمل البوابة، وتظهر الحلقات دون حماية — وهذا متوقَّع في الموقع الساكن.

## ملاحظات النسخة (v5)

- توحيد القوالب: رأس/تذييل/قائمة واحدة على كل الصفحات، وتصحيح وسم «الدخول إلى الموسم».
- صفحة الدخول: الخطوات الثلاث + ملاحظة الخصوصية + رسالة باسورد لطيفة + حالة «أنت داخل الموسم» + زر إنهاء الوصول + رسالة عند تعطيل JavaScript.
- البوابة تستخدم `localStorage` باتساق، مع زر إنهاء الوصول.
- الحلقة العاشرة باسم **«الخلاصة العملية»** بدل أي إشارة للماستر فورم.
- صورة مشاركة PNG (1200×630) للمعاينة على وسائل التواصل، مع وسوم Open Graph و Twitter.
- إضافة `vercel.json` للروابط النظيفة، وتحديث الـ README وحذف أي إشارة للماستر فورم.

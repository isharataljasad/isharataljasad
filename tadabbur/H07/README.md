# H07 — الحزب السابع (آل عمران ٩٢–١٧٠)

| الملف | الوصف |
|---|---|
| `H07-DRAFT-R02.md` / `.txt` | **النسخة الحالية للمراجعة** (متطابقتان بايتيًا). غير معتمدة لإنتاج الصور. |
| `H07-R02-CHANGELOG.md` | سجل تعديلات R02 (نسخة من القسم ٦ في المسودة). |
| `evidence-R02/` | صور إثبات تصحيحات علامات الوقف، ولوحات المصحف ٦٢–٧٢. |
| `H07-DRAFT-R01.md` / `.txt` | النسخة السابقة (للأرشيف). |
| `work/` | ملفات إعادة التوليد. |

إعادة التوليد: `cd work && python3 blocks.py && python3 gen.py ../H07-DRAFT-R02.md`

- `q_final.json`: نص الآيات ٩٢–١٧١ مع علامات الوقف المطابَقة بصريًا (`waqf_overrides.py` و`apply_waqf.py`).
- `edits_R02.py` و`changelog_R02.json`: تعديلات التدبر والمحطات والخلاصات، مع النص قبل التعديل وبعده.
- `fixes.py` و`blocks.py`: نص السعدي وتصحيحات المقابلة البصرية.

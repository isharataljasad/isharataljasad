# H07 — الحزب السابع (آل عمران ٩٢–١٧٠)

- `H07-DRAFT-R01.md`: المسودة النصية الكاملة للمراجعة. لم تُنتَج صور.
- `work/`: ملفات إعادة التوليد للنسخ اللاحقة:
  - `lines.json`: نص السعدي المستخرج من ملف الحزب السابع، سطرًا سطرًا مع رقم صفحة PDF.
  - `fixes.py`: التصحيحات اليدوية بعد المقابلة البصرية.
  - `blocks.py`: بناء مقاطع التفسير لكل بطاقة.
  - `q.txt`: نص الآيات ٩٢–١٧١ المطابَق بصريًا مع المصحف.
  - `content.py`: العناوين والتدبر والمحطات.
  - `gen.py`: توليد المسودة.

لإعادة التوليد: `cd work && python3 blocks.py && python3 gen.py ../H07-DRAFT-R02.md`

## In plain English

The three parallel "routes" per subject (Book, Pearson, Educator) and their 333
short notes have been merged into **one ordered set of lessons per subject**:

- **Entrance:** three subject cards, each with one button. No counts.
- **Subject page:** a numbered list of lessons, read in order.
- **Lesson:** always the same pattern: what it explains → before you begin →
  the idea with a diagram → the formulas (symbols, units, conditions, why it
  works) → a first worked example → a different case → more cases → common
  misunderstandings (plus collapsed, optional depth) → keep in mind and the next
  lesson.
- **Sources and credits:** one quiet page per subject. It says the text is
  original, credits OpenStax (CC BY 4.0) for Chemistry, and lists the optional
  Pearson Channels videos with a note that Pearson has not reviewed or endorsed
  the library and that the site may need an account. No lesson needs a
  publisher account.
- **Old links** still work (see `docs/compatibility-map.md`).
- **No feedback form** was added, because no destination for feedback is
  configured (see `docs/pilot-feedback-proposal.md`).

## Science review

Every lesson was read in full for correctness, order, English, formula meaning,
symbols, units, conditions and duplication. Corrections include:

- **Tangent wording:** the tangent line is defined as the limit of secant lines
  whose slope is the derivative. It may cross the curve (y = x³ at 0). The phrase
  "just touches" is gone, and a test keeps it out.
- Limits: the 0/0 statement; the IVT now says N is *strictly* between f(a) and
  f(b); the misconception about 1/x was rewritten.
- Functions: horizontal scaling wording, the nth-root domain condition, symbol
  units.
- Forces: the scope line no longer says torque is excluded, since there is now
  an optional torque section. Laboratory graphs: the stated spread of F/x ratios
  now matches the table (195–210 N/m).
- Reactions in solution: the mole-ratio condition was corrected (a ratio holds
  for any pair in a balanced equation; the limiting reactant decides the amount
  of product).
- Lines that claimed what a *later* course contains (Ksp, entropy, acid–base
  equilibria, "archived for a later course") were replaced by neutral scope
  statements.
- The promoted Chemistry lessons now use the same (British) spelling as the rest.
- Worked examples were reordered so that each lesson starts with the most basic
  case (for example, balancing now comes before stoichiometry).
- Two figures were corrected: a label overlap in the Functions diagram. A
  charge-balance diagram was added to Chemical naming, the only lesson that had
  no figure.

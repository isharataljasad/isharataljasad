# Expressions and variables

**Episode 01.1 | Basic Math | Early reading edition**

## What this lesson will settle

By the end, you should be able to tell a variable from a value, distinguish an expression from an equation, translate a short phrase into symbols, and evaluate an expression when its variables are assigned numbers. Those are four different decisions; getting one right does not automatically establish the others.

## 1. A variable is a named place for a number

Suppose a container holds an unknown volume. We may write `V` for that volume. The letter is not a secret operation: it stands for a number whose value depends on the situation. When we later learn `V = 6 L`, we can replace `V` by `6 L` in a calculation. In another situation, `V` might represent a different number. The **meaning and unit** should be stated before we calculate.

A letter can also be used for a fixed but unspecified number, such as a chosen constant. The shape of the letter does not tell us whether it varies or is fixed; the problem's definition does.

## 2. An expression represents a value

`12 + 5` is a numerical expression. `3V + 2` is an algebraic expression because it contains a variable. “Three times the volume, then add two” is a verbal expression describing the same operation. An expression can be evaluated, but it does not claim two sides are equal.

Compare these:

| Written form | What it is | What you can ask |
| --- | --- | --- |
| `3V + 2` | Expression | What value does it have when `V` is known? |
| `3V + 2 = 20` | Equation | Which values of `V` make the statement true? |
| `3V + 2 > 20` | Inequality | Which values of `V` satisfy the comparison? |

The distinction matters: **evaluate** means calculate the value for assigned inputs; **simplify** means rewrite without changing the value; **solve** means find values that make an equation or inequality true.

## 3. Read the operations before using numbers

Adjacent symbols can mean multiplication: `4x` means `4 × x`, and `ab` means `a × b`. An exponent is different: `x²` means `x × x`, while `2x` means `2 × x`. Parentheses tell us which operation is grouped first. For example, `3(x + 2)` means three copies of the whole sum, whereas `3x + 2` adds two only after multiplying `x` by three.

Division needs one more condition. In `a/b`, the value of `b` cannot be zero. A formula may look readable while failing for a forbidden input.

## 4. Evaluate by substitution, then calculate

Suppose a service charges `p` riyals per item, sells `q` items, and adds a fixed delivery charge of `d` riyals. Its total charge is `pq + d`. If `p = 7`, `q = 4`, and `d = 3`, substitute first: `(7)(4) + 3 = 31` riyals. Estimate before computing: four items at about seven riyals cost about 28, so 31 is plausible.

Substitution must respect grouping. If `x = -2`, then `x² = (-2)² = 4`; writing `-2²` without parentheses usually means `-(2²) = -4`. The number and the negative sign have to be placed deliberately.

## Coverage before questions

This explanation has covered the meaning of a variable, three ways to present an expression, the difference between expression/equation/inequality, multiplication by adjacency, exponents, grouping, valid division, and substitution with units. If any of those is unclear, return to its section before trying the checks.

## Five question fingerprints

1. **Classify:** Is `5n - 1 = 14` an expression or an equation? What changes if the equals sign is removed?
2. **Translate:** Write “four times the sum of `r` and three” using symbols. Explain why `4r + 3` says something different.
3. **Evaluate:** Find `2a² + b` when `a = -3` and `b = 5`.
4. **Diagnose:** A student evaluates `xy` at `x = 6`, `y = 2` as `62`. What operation did the student miss?
5. **Transfer:** A solution has concentration `c` moles per litre and volume `V` litres. What does `cV` represent, and what is its unit?

## Answers with reasons

1. It is an **equation** because it asserts equality. Without `= 14`, `5n - 1` is an expression that has a value for each allowed `n`.
2. `4(r + 3)`. The parentheses put both `r` and `3` inside the multiplication. `4r + 3` multiplies only `r` by four.
3. `2(-3)² + 5 = 2(9) + 5 = 23`. Squaring the negative input gives a positive square.
4. Adjacency means multiplication: `xy = 6 × 2 = 12`, not concatenation of the digits.
5. `cV` is amount of substance, measured in moles, because `(mol/L) × L = mol`. The unit check explains why multiplication is appropriate.

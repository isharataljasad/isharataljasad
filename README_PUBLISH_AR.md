# إضافة أول مسار نشر إلى موقع إشارات الجسد

## الملفات المضافة

- `body.html`  ← صفحة خريطة الجسم
- `body/skin.html` ← صفحة نظام/عضو الجلد
- `body/skin/epidermoid-cyst.html` ← مقال الكيس الدهني
- `assets/css/fuad-web.css` ← ستايل مشترك للصفحات الجديدة

## المسار الذي يراه القارئ

الرئيسية → خريطة الجسم → الجلد → الكيس الدهني

## طريقة الرفع على GitHub + Vercel

1. افتح مستودع الموقع في GitHub.
2. ارفع الملفات بنفس المسارات الموجودة داخل هذا ZIP.
3. لا تستبدل `index.html` الآن إلا إذا أردت تغيير الصفحة الرئيسية.
4. بعد الرفع، Vercel سيعمل Deploy تلقائيًا.
5. افتح:
   - `/body.html`
   - `/body/skin.html`
   - `/body/skin/epidermoid-cyst.html`

## ربط الصفحة الرئيسية لاحقًا

أضف في قائمة الموقع الحالية رابطًا إلى:

```html
<a href="/body.html">خريطة الجسم</a>
```

## ملاحظة

هذه النسخة Drop-in ولا تلمس الصفحة الرئيسية الحالية.

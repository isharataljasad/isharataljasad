Limits

A limit describes the value a function approaches near a point, not the value at the point.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Every idea in calculus is built on limits. The derivative (instantaneous rate of change) is a limit of average rates, and continuity is defined with a limit. Engineers use limits whenever a quantity cannot be evaluated directly at a point but its behaviour close to that point is known: the speed at one instant, the steady value a process settles to, or a formula that breaks down at a single input.

The idea

Think of walking along the graph of a function towards the input x = a. The limit asks: what height are you heading towards? It does not ask what happens exactly at x = a. The function may have a different value there, or no value at all, and the limit is unaffected.

For example, f(x) = x2 − 9 / x − 3 cannot be evaluated at x = 3, because the denominator is zero. For every other input, the numerator factors as (x − 3)(x + 3), so f(x) = x + 3 whenever x ≠ 3. Near 3 the outputs are close to 6, so the limit is 6, even though f(3) does not exist. The graph is a straight line with a single hole.

You approach a point from two sides. Coming from inputs smaller than a gives the left-hand limit; coming from larger inputs gives the right-hand limit. The (two-sided) limit exists only when both one-sided limits exist and agree.

When direct substitution produces the expression 0 / 0, the calculation is not finished: 0 / 0 is not a number. It is a signal that the numerator and denominator share a factor that vanishes at the point. The task is to rewrite the expression, using algebra that is valid for inputs near a (but not at a), until substitution works.

Background you need

Factoring

Difference of squares: a2 − b2 = (a − b)(a + b), so x2 − 9 = (x − 3)(x + 3). A quadratic x2 + bx + c factors as (x + p)(x + q) when p + q = b and pq = c; for example x2 − 5x + 6 = (x − 2)(x − 3).

Cancelling in a fraction

A common factor may be cancelled only when it is not zero. The statement (x − 3)(x + 3) / x − 3 = x + 3 is true for every x except x = 3. A limit never uses the input x = a itself, so inside a limit the cancellation is valid.

Conjugates

Multiplying √A − B by its conjugate √A + B gives A − B2, which removes the square root. Multiplying the numerator and the denominator by the same non-zero expression does not change the value of a fraction.

An example, explained

Factoring a 0/0 form

Problem. Find limx→2 x2 − 4 / x − 2.

  1. Substitute x = 2: numerator 4 − 4 = 0, denominator 2 − 2 = 0. The form is 0 / 0.

    Substitution first tells us whether more work is needed.

  2. Factor the numerator: x2 − 4 = (x − 2)(x + 2).

    Zero in both parts means (x − 2) is a common factor.

  3. Cancel (x − 2), valid because x ≠ 2 inside the limit: the expression becomes x + 2.

    The limit never uses x = 2 itself.

  4. Substitute into the polynomial: 2 + 2 = 4.

    Direct substitution is valid for polynomials.

Result: limx→2 x2 − 4 / x − 2 = 4.

What it means: The graph is the line y = x + 2 with a hole at (2, 4).

Common misunderstandings

  • Misunderstanding: “Substitution gives 0/0, so the limit is 0 (or 1, or does not exist).”

    Correct idea: 0/0 is not an answer. limx→0 x/x = 1, limx→0 x2/x = 0 and limx→0 5x/x = 5 all give 0/0 on substitution but have different limits.

  • Misunderstanding: “The limit is the same as the value f(a).”

    Correct idea: Only for continuous functions. A function can have a limit where it is undefined (the hole above) or a value different from its limit.

  • Misunderstanding: “If the left-hand limit exists, the limit exists.”

    Correct idea: You must check both sides. One side alone can prove that a limit does not exist (if it disagrees with the other), never that it exists.

  • Misunderstanding: Treating ∞ as a number, e.g. “∞ − ∞ = 0”.

    Correct idea: Forms such as ∞ − ∞ and ∞/∞ are indeterminate. Rewrite the expression (for example divide by the highest power) before concluding.

  • Misunderstanding: Using degrees in limx→0 sin x / x.

    Correct idea: The value 1 requires radians. Calculators set to degrees give about 0.01745.

04

Investigating a limit

Meaning

A limit describes what outputs approach near an input, not necessarily the output at that input. Both one-sided approaches must agree for a finite two-sided limit.

Method

Use a graph to see approach direction and a table of nearby inputs on both sides to estimate. Then seek an algebraic argument: numerical evidence alone can mislead near a sharp feature. Separate a hole, jump, vertical asymptote, and oscillation.

Worked reasoning

For f(x)=(x²−4)/(x−2) with x≠2, nearby outputs approach 4 because f(x)=x+2 away from 2. The value f(2) remains undefined; the limit is 4.

Additional worked example

If f(x)=−1 for x<0 and f(x)=2 for x≥0, what is lim as x→0 of f(x)?

The left limit is −1 and the right limit is 2; the two-sided limit does not exist.

Common error. A table with values only on one side cannot establish a two-sided limit.

05

Algebraic limit methods

Meaning

Direct substitution works when the expression remains continuous. An apparent 0/0 signals algebra to perform, not a numerical answer.

Method

Factor and cancel a common nonzero factor near the point; rationalize radicals; or divide by the dominant power for behavior at infinity. For a trigonometric limit, rewrite it to expose sin(u)/u and account for any scale factor. Use one-sided signs to analyze a denominator tending to zero without cancellation.

Worked reasoning

lim as x→3 of (x²−9)/(x−3) equals lim(x+3)=6 after factoring. In contrast, lim as x→∞ of (3x²−1)/(2x²+5)=3/2 after division by x².

Additional worked example

Evaluate lim as x→0 of sin(5x)/x.

Rewrite as 5[sin(5x)/(5x)]; the inner ratio tends to 1, so the limit is 5.

Common error. Cancellation is legal for x near the target, not at the point where the original denominator is zero.

06

Formal definition of a limit

Meaning

The epsilon–delta definition makes “arbitrarily close” exact: every requested output tolerance ε>0 must admit an input tolerance δ>0.

Method

Start with |f(x)−L| and bound it by an expression containing |x−a|. Choose δ as a function of ε. When another factor varies with x, first keep x within a simple neighborhood such as |x−a|<1, then control the remaining factor.

Worked reasoning

To prove lim as x→3 of (2x+1)=7, observe |(2x+1)−7|=2|x−3|. Choosing δ=ε/2 makes 0<|x−3|<δ imply the required bound.

Additional worked example

Choose δ for lim as x→4 of (3x−2)=10.

Because |(3x−2)−10|=3|x−4|, δ=ε/3 works for every ε>0.

Common error. δ may depend on ε, but a proof cannot choose ε after choosing a particular x.

Continuity

A function is continuous at a point when its limit there exists and equals its value: no holes, jumps or breaks.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Continuity is the mathematical version of “no sudden breaks”. Temperatures, positions and concentrations in physical processes change continuously, and many theorems of calculus (the Intermediate Value Theorem, the Extreme Value Theorem and the Mean Value Theorem) only work for continuous functions. Before you use one of those theorems you must check continuity.

Continuity also tells you when direct substitution is allowed: at a point of continuity, the limit is simply the value.

The idea

Informally, a function is continuous on an interval if you can draw its graph there without lifting your pen. Precisely, continuity at a single point x = a requires three things to happen together: f(a) is defined, limx→a f(x) exists, and the two are equal.

When one of the three conditions fails we have a discontinuity, and its type tells you what went wrong. A removable discontinuity is a hole: the limit exists but the value is missing or different; redefining one value repairs it. A jump discontinuity has different one-sided limits; no single value can repair it. An infinite discontinuity has the function growing without bound, as with 1 / x at 0.

Most functions you meet are continuous wherever they are defined: polynomials everywhere; rational functions except where the denominator is zero; √x for x ≥ 0; sin x and cos x everywhere; ex everywhere and ln x for x > 0. Sums, products and compositions of continuous functions are continuous, and so are quotients wherever the denominator is not zero. The places to check carefully are the “joins” of piecewise functions and the zeros of denominators.

Continuity on a closed interval [a, b] guarantees the Intermediate Value Theorem: the function takes every value between f(a) and f(b). In particular, if f(a) and f(b) have opposite signs, the equation f(x) = 0 has a solution between a and b. This is how we know an equation has a root before we can find it.

Background you need

Limits and one-sided limits

limx→a f(x) = L means f(x) approaches L as x approaches a from both sides (see the Limits topic). For a piecewise function, the left-hand limit uses the rule for x < a and the right-hand limit uses the rule for x > a.

Domains

A rational function is undefined where its denominator is zero; √u needs u ≥ 0; ln u needs u > 0. A function cannot be continuous at a point where it is not defined.

An example, explained

Repair a removable discontinuity

Problem. f(x) = 2x + 1 for x ≠ 2. What value of f(2) makes f continuous at 2?

  1. limx→2 (2x + 1) = 5.

    2x + 1 is a polynomial, so substitute x = 2.

  2. Continuity needs f(2) = limx→2 f(x).

    The third condition of the definition.

Result: Define f(2) = 5.

What it means: Filling the hole with the limiting value makes the graph an unbroken line.

Common misunderstandings

  • Misunderstanding: “f(a) exists, so f is continuous at a.”

    Correct idea: The value is only the first of three conditions. The limit must also exist and equal f(a).

  • Misunderstanding: “The limit exists, so f is continuous.”

    Correct idea: The limit may differ from the value (a removable discontinuity), or the value may be missing.

  • Misunderstanding: Using the wrong rule at the join of a piecewise function.

    Correct idea: Read the inequality signs: with “x ≥ 1”, f(1) comes from the second rule, but the left-hand limit comes from the first.

  • Misunderstanding: “The IVT tells us where the root is.”

    Correct idea: It only guarantees that at least one root exists in the interval. Finding it needs further work (for example, repeated halving).

  • Misunderstanding: “1/x is discontinuous, so it is not a continuous function.”

    Correct idea: 1/x is continuous at every point of its domain (x ≠ 0). It is discontinuous at 0, which is not in its domain. Always say where.

07

Continuity and the intermediate value theorem

Meaning

Continuity at a means f(a) exists, the limit exists, and they agree. For a continuous function on [a,b], every value between f(a) and f(b) is attained somewhere inside.

Method

Check domain and one-sided behavior before invoking continuity. A hole can be repaired by assigning the limiting value; a jump generally cannot. For an existence question, identify a continuous interval and show the target lies between endpoint outputs.

Worked reasoning

Let f(x)=x³−x−1. It is continuous. Since f(1)=−1 and f(2)=5, some c in (1,2) satisfies f(c)=0, even without an explicit root.

Additional worked example

Can the intermediate value theorem prove that x²−2 has a root between 1 and 2?

Yes. The polynomial is continuous, and its endpoint values are −1 and 2, so zero lies between them.

Common error. The theorem guarantees existence; it does not give a formula or prove uniqueness.

Derivative as a rate

The derivative is the instantaneous rate of change: the limit of average rates, and the slope of the tangent line.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Engineering is full of rates: velocity is the rate of change of position, reaction rate is the rate of change of concentration, power is the rate of change of energy. An average rate over an interval is easy to compute, but often we need the rate at one instant. The derivative gives exactly that, and all later calculus (rules, optimization, related rates, approximation) is built on it.

The idea

Start with an average rate of change. Between x = a and x = a + h, the output changes by f(a + h) − f(a) while the input changes by h. Their ratio f(a + h) − f(a) / h is the slope of the secant line through the two points of the graph.

Now shrink the interval. As h → 0 the second point slides along the curve towards the first, and the secant line turns into the tangent line, the line that just touches the curve at x = a. The limit of the secant slopes is the derivative f′(a). We cannot simply put h = 0, because the quotient would become 0 / 0; that is exactly why a limit is needed.

The derivative has units: output units divided by input units. If s is position in metres and t is time in seconds, s′(t) is in m/s. If C is concentration in mmol/L and t is in minutes, C′(t) is in mmol/(L·min). The sign tells you the direction: f′(a) > 0 means f is increasing at a, f′(a) < 0 means it is decreasing.

Doing this at every point gives a new function, the derivative function f′(x). A function is differentiable at a if this limit exists. A differentiable function is always continuous, but a continuous function need not be differentiable: |x| has a corner at 0, where the slope from the left is −1 and from the right is +1, so no single tangent slope exists.

Background you need

Slope of a line

The slope between (x1, y1) and (x2, y2) is m = y2 − y1 / x2 − x1. The line through (a, b) with slope m is y − b = m(x − a).

Expanding brackets

(a + h)2 = a2 + 2ah + h2 and (a + h)3 = a3 + 3a2h + 3ah2 + h3. After subtracting f(a), every remaining term contains h, so h can be cancelled.

Limits of 0/0 forms

Cancel a common factor that is non-zero for the inputs the limit uses (h ≠ 0), then substitute. See the Limits topic.

An example, explained

Derivative at a point from the definition

Problem. For f(x) = x2 + 3x, find f′(2) from the definition.

  1. f(2 + h) = (2 + h)2 + 3(2 + h) = 4 + 4h + h2 + 6 + 3h = 10 + 7h + h2.

    Replace x by 2 + h and expand.

  2. f(2) = 4 + 6 = 10, so f(2 + h) − f(2) = 7h + h2.

    The constant terms cancel.

  3. 7h + h2 / h = 7 + h for h ≠ 0.

    Cancel the common factor h.

  4. Let h → 0: f′(2) = 7.

    Substitute h = 0 in 7 + h.

Result: f′(2) = 7.

What it means: Near x = 2 the output increases about 7 units for each unit increase in x.

Common misunderstandings

  • Misunderstanding: Putting h = 0 immediately in the difference quotient.

    Correct idea: That gives 0/0. Simplify and cancel h first, then take the limit.

  • Misunderstanding: Confusing the average rate with the instantaneous rate.

    Correct idea: The average rate uses two points; the derivative is the limit as the interval shrinks to one point.

  • Misunderstanding: Writing the tangent line as y = f′(a)x.

    Correct idea: The line must pass through (a, f(a)): y = f(a) + f′(a)(x − a).

  • Misunderstanding: Forgetting units.

    Correct idea: A derivative is a rate: output units per input unit, for example m/s or mmol/(L·min).

  • Misunderstanding: “Continuous means differentiable.”

    Correct idea: Corners and cusps (|x| at 0) are continuous but have no derivative.

03

Average and instantaneous change

Meaning

Average change is the slope of a secant line across an interval. Instantaneous change is the limiting secant slope at one input, if that limit exists.

Method

Compute output change divided by input change and keep units: output units per input unit. To approach an instantaneous rate, replace the interval by [a,a+h], simplify while h≠0, and take h→0. The tangent slope can be positive, zero, or negative.

Worked reasoning

For f(x)=x² at x=2, the secant slope over [2,2+h] is [(2+h)²−4]/h=4+h. Its limit is 4.

Additional worked example

Find the average rate of f(x)=1/x on [2,4].

[(1/4)−(1/2)]/(4−2)=−1/8. The negative sign records decreasing output as x increases.

Common error. Never treat an average rate over a finite interval as the rate at either endpoint.

08

Derivative from its limit definition

Meaning

The derivative is the limit of difference quotients and represents local slope or instantaneous rate. Differentiability requires a finite common limit from both sides.

Method

Substitute f(a+h), subtract f(a), simplify the numerator, cancel h while h≠0, then take h→0. For radicals, multiply by the conjugate. At a corner or cusp, compare one-sided slopes.

Worked reasoning

For f(x)=√x and a>0, [√(a+h)−√a]/h becomes 1/[√(a+h)+√a] after rationalization. Hence f′(a)=1/(2√a).

Additional worked example

Use the definition to find the derivative of f(x)=x²+1 at x=3.

The quotient is [(3+h)²+1−10]/h=6+h; its limit is 6.

Common error. Substituting h=0 before simplifying creates 0/0 and loses the limiting slope.

12

Rates of change in context

Meaning

A derivative inherits context and units. Position yields velocity; velocity yields acceleration. Speed is |velocity|, so direction and speed are distinct.

Method

Write the physical quantity as a function of time, differentiate, evaluate at the requested time, then report units. For landing or a turning point, solve the relevant equation first and reject times outside the physical domain.

Worked reasoning

If s(t)=80−16t² feet, then v(t)=−32t feet/second. The object reaches ground when 80−16t²=0, so t=√5 seconds; its impact velocity is −32√5 feet/second.

Additional worked example

For s(t)=t³−6t² meters, find velocity and acceleration at t=2 seconds.

v(t)=3t²−12t, so v(2)=−12 m/s. a(t)=6t−12, so a(2)=0 m/s².

Common error. A negative velocity means direction, not negative speed.

16

Equation of a tangent line

Meaning

A tangent line passes through (a,f(a)) with slope f′(a). Its local agreement with the curve is first order.

Method

Identify the requested x-coordinate a, evaluate f(a), compute f′(a), and insert both into point–slope form. Verify that the result passes through the point and has a plausible slope.

Worked reasoning

For f(x)=x² at a=3, the point is (3,9) and slope is 6. Thus y−9=6(x−3), or y=6x−9.

Additional worked example

Find the tangent line to y=eˣ at x=0.

The point is (0,1) and slope is 1, giving y=x+1.

Common error. The derivative value is the slope, not the y-coordinate of the tangency point.

Differentiation rules

Rules that give derivatives quickly and reliably: power, sum, product, quotient and chain rules, with the derivatives of trigonometric, exponential and logarithmic functions.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Computing every derivative from the limit definition is slow and error-prone. The rules below are consequences of that definition; once you trust them, you can differentiate almost any formula that appears in engineering models, from polynomials to damped oscillations and exponential decay.

The idea

Every formula is built from simple functions (powers, sin, ex, ln x) combined by a few operations: adding, multiplying, dividing, and putting one function inside another. There is one rule for each operation. The skill is to read the structure of the formula: which operation would you do last if you evaluated it at a number? That operation decides the first rule to use.

The power rule says that the derivative of xn is nxn−1: the exponent comes down and decreases by one. Constants multiply through and sums split term by term, because limits behave that way.

For a product f·g, both factors change, so both contribute: (fg)′ = f′g + fg′. It is not f′g′. For a quotient, (f/g)′ = (f′g − fg′)/g2; the order in the numerator matters because of the minus sign.

For a composition f(g(x)) — a function of a function — the rates multiply: if the inside changes at rate g′ and the outside responds at rate f′ (evaluated at the inside), the total rate is f′(g(x))·g′(x). This is the chain rule. Forgetting the inside derivative is the most common error in all of calculus.

Trigonometric derivatives such as (sin x)′ = cos x are only true when x is in radians, because they depend on lim sin h / h = 1. The exponential ex is its own derivative, and ln x has derivative 1/x for x > 0.

Background you need

Exponent laws

√x = x1/2, 1 / xn = x−n, xa·xb = xa+b. Rewrite roots and reciprocals as powers before using the power rule: 1 / √x = x−1/2.

Composition

In f(g(x)), g is the inside function and f the outside. For (2x + 5)4, the inside is u = 2x + 5 and the outside is u4. For sin(x2) the inside is x2 and the outside is sin.

Radians

π radians = 180°. Calculus formulas for sin, cos and tan assume radians.

An example, explained

Power and sum rules

Problem. Differentiate y = 4x3 − 6 / x + 2√x.

  1. Rewrite: y = 4x3 − 6x−1 + 2x1/2.

    Every term becomes a power of x.

  2. Differentiate term by term: 12x2 − 6(−1)x−2 + 2·1 / 2x−1/2.

    Bring down each exponent and reduce it by one.

Result: y′ = 12x2 + 6 / x2 + 1 / √x (for x > 0).

What it means: The domain x > 0 comes from √x in the original function and 1/√x in the derivative.

Common misunderstandings

  • Misunderstanding: (fg)′ = f′g′.

    Correct idea: The product rule has two terms: f′g + fg′. Check with x·x = x²: f′g′ = 1, but the true derivative is 2x.

  • Misunderstanding: Forgetting the inside derivative: (sin 3x)′ = cos 3x.

    Correct idea: The chain rule multiplies by the inside derivative: (sin 3x)′ = 3cos 3x.

  • Misunderstanding: Reversing the quotient-rule numerator.

    Correct idea: It is f′g − fg′ (derivative of the top first). The reversed order gives the wrong sign.

  • Misunderstanding: Applying the power rule to ex or 2x: (ex)′ = xex−1.

    Correct idea: The power rule needs a variable base and constant exponent. For a constant base: (ex)′ = ex, (2x)′ = 2x ln 2.

  • Misunderstanding: Using degrees in trigonometric derivatives.

    Correct idea: The formulas require radians.

  • Misunderstanding: Treating arcsin x as 1/sin x.

    Correct idea: arcsin is the inverse function (angle whose sine is x); 1/sin x is csc x.

09

Power, constant, and sum rules

Meaning

Power rules replace repeated limit calculations for polynomial, reciprocal, and radical powers wherever the expression is differentiable.

Method

Rewrite roots and reciprocals as exponents, differentiate each term, and retain constants as coefficients. A standalone constant has derivative zero. Check the original domain, since rewriting a negative power does not create a value at x=0.

Worked reasoning

For f(x)=3x⁴−2√x+5/x, rewrite as 3x⁴−2x^(1/2)+5x^(−1). Then f′(x)=12x³−x^(−1/2)−5x^(−2), for x>0.

Additional worked example

Differentiate 4/x³−7x²+9.

Write 4x^(−3)−7x²+9. The derivative is −12x^(−4)−14x.

Common error. The exponent falls by one after multiplying by the original exponent; it does not simply fall by one.

10

Product rule

Meaning

Two changing factors contribute separately to the change in their product. A derivative of a product is generally not the product of derivatives.

Method

Label the factors before differentiating. Differentiate one while holding the other, then reverse and add. Expand first only when that makes the algebra simpler; both routes must agree.

Worked reasoning

For y=(x²+1)eˣ, y′=2xeˣ+(x²+1)eˣ=eˣ(x²+2x+1).

Additional worked example

Differentiate (x³−2)sin x.

3x² sin x+(x³−2)cos x.

Common error. Both product-rule terms must appear, even if one factor looks simple.

11

Quotient rule

Meaning

When a numerator and denominator both vary, their effects oppose one another in the derivative.

Method

Name numerator f and denominator g, write “denominator times numerator derivative minus numerator times denominator derivative,” and divide by g². Preserve parentheses in the numerator. If the denominator is a simple power, rewriting as a negative exponent may be shorter.

Worked reasoning

For y=(x²+1)/x, the quotient rule gives [2x·x−(x²+1)]/x²=(x²−1)/x². Rewriting y=x+1/x gives the same 1−1/x².

Additional worked example

Differentiate sin x / x, for x≠0.

[x cos x−sin x]/x².

Common error. The denominator is squared as a whole; changing the order in the numerator changes the sign.

13

Derivatives of trigonometric functions

Meaning

The basic trigonometric derivatives support repeated differentiation of oscillating quantities. These rules require angles measured in radians.

Method

Related rates

When quantities are linked by an equation, their rates of change are linked too. Differentiate the equation with respect to time.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

In real systems several quantities change at the same time and depend on each other: the level and the volume of liquid in a tank, the radius and the area of a spreading spill, the pressure and volume of a gas. Often one rate is easy to measure and another is what you need. Related rates turn a geometric or physical relationship into a relationship between rates.

The idea

Suppose two quantities x and y both depend on time t and are always connected by an equation, such as x2 + y2 = 25 for a ladder of length 5 m. Because the equation holds at every instant, the two sides change at the same rate. Differentiating both sides with respect to t (using the chain rule) gives an equation connecting dx / dt and dy / dt.

The chain rule is the key step. Since x is a function of t, d / dt(x2) = 2xdx / dt, not 2x. Every variable that changes with time brings its own rate factor.

There is one crucial order of operations: differentiate first, substitute the instantaneous values second. If you substitute x = 3 before differentiating, x becomes a constant and its rate disappears. Only quantities that are genuinely constant (a fixed ladder length, a fixed tank cross-section) may be substituted before differentiating.

Signs carry meaning. A negative rate means the quantity is decreasing. In the ladder problem the top slides down, so dy / dt comes out negative, and that is correct.

Linear approximation

Near a point, a differentiable function is almost a straight line: its tangent line gives quick estimates and error sizes.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Engineers constantly replace complicated functions by simpler ones that are accurate enough nearby: small-angle approximations, linearised models of reactors and circuits, and error estimates for measurements. The tangent line is the simplest such replacement, and differentials tell you how an error in a measured input spreads to a calculated output.

The idea

If you zoom in far enough on a smooth curve, it looks like a straight line — its tangent line. So near x = a we can approximate f(x) by the tangent line L(x) = f(a) + f′(a)(x − a). This is the linear approximation (or linearisation) of f at a.

Choose a as a point where f is easy to evaluate exactly and close to the input you care about. To estimate √4.08, use a = 4 because √4 = 2 is known exactly.

The approximation is only good near a. The error grows as x moves away, and its size depends on how strongly the graph bends (the second derivative). If the graph is concave down (bending below its tangents), the tangent line lies above the curve and the estimate is too large; if concave up, the estimate is too small.

The same idea in “change” language: a small change dx in the input produces a change in output of about dy = f′(x) dx. This differential is the change along the tangent line. It is how measurement errors propagate: if a radius is measured with a small error, the resulting error in a computed area is about A′(r) × (error in r).

Rolle and Mean Value Theorems

If a smooth function goes from one value to another, somewhere its instantaneous rate equals its average rate.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

The Mean Value Theorem (MVT) connects an average rate over an interval with an instantaneous rate at some point inside. It is the reason we can say “if f′ > 0 everywhere, f is increasing”, “if f′ = 0 everywhere, f is constant”, and it gives bounds such as “if the speed never exceeds 90 km/h, then in 2 hours you travel at most 180 km”.

It is also a lesson in reading theorems carefully: the conclusion is guaranteed only when the hypotheses are checked.

The idea

Drive 120 km in 1.5 hours: your average speed is 80 km/h. Common sense says your speedometer must have read exactly 80 km/h at some moment — you cannot average 80 without passing through 80 if your speed changes smoothly. The MVT is the precise version of this.

Geometrically: join the endpoints (a, f(a)) and (b, f(b)) of the graph with a secant line. Somewhere between a and b there is a point c where the tangent line is parallel to the secant, so f′(c) equals the secant slope f(b) − f(a) / b − a.

Rolle’s theorem is the special case f(a) = f(b): the secant is horizontal, so somewhere inside the tangent is horizontal, f′(c) = 0. A ball thrown up and caught at the same height has zero vertical velocity at the top.

Both theorems need two hypotheses: f continuous on the closed interval [a, b] and differentiable on the open interval (a, b). Without them the conclusion can fail. |x| on [−1, 1] has f(−1) = f(1), but no horizontal tangent, because of the corner at 0. The theorems promise existence of at least one c; they do not say how many or where. In simple examples we can locate c by solving f′(c) = slope.

Extrema and curve shape

The first derivative shows where a graph rises and falls; the second shows how it bends. Together they locate maxima, minima and inflection points.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Before computers drew graphs, engineers sketched them from derivatives — and they still check computer output that way. More importantly, locating maxima and minima is the basis of optimization: the largest yield, the smallest cost, the strongest beam. This topic gives the tests; the next applies them.

The idea

The sign of f′ tells you the direction of the graph: f′ > 0 on an interval means f is increasing there, f′ < 0 means decreasing. (This follows from the Mean Value Theorem.) The graph can only turn around where f′ = 0 or where f′ does not exist. Those inputs, inside the domain, are the critical points.

A critical point is only a candidate. At a local maximum the graph rises then falls, so f′ changes from + to −; at a local minimum f′ changes from − to +. If f′ does not change sign (as for x3 at 0), there is no extremum at all. This is the first-derivative test.

The sign of f″ tells you how the graph bends. f″ > 0: concave up, shaped like a cup, with slopes increasing. f″ < 0: concave down, shaped like a cap. A point where the concavity changes is an inflection point. The second-derivative test: if f′(c) = 0 and f″(c) > 0 the point is a local minimum (bottom of a cup); if f″(c) < 0 it is a local maximum. If f″(c) = 0 the test says nothing and you must use the first-derivative test.

On a closed interval [a, b], a continuous function always has an absolute maximum and an absolute minimum (the Extreme Value Theorem). They occur either at critical points or at the endpoints, so you find them by comparing the function values at all these candidates. Forgetting the endpoints is a classic error.

For a full sketch, also check the domain, intercepts, symmetry and asymptotes (the behaviour as x → ±∞ and near points where the function is undefined).

Optimization

Turn a “best design” question into a function of one variable on an interval, then use derivatives to find and justify the optimum.

Compare this topic:BookPearsonEducatorFull guide

Why it matters

Optimization is where calculus pays for itself in engineering: minimum material for a container of given volume, maximum power transfer, minimum cost or energy, maximum yield. The mathematics is the closed-interval method and the derivative tests; the real skill is building the right model and checking that the answer makes physical sense.

The idea

Every optimization problem has an objective (the quantity to maximise or minimise, such as area, volume or cost) and one or more constraints (fixed conditions, such as a given perimeter or volume). The constraint lets you eliminate variables until the objective depends on a single variable.

The variable also has a feasible interval: lengths must be positive, a cut cannot exceed half the sheet, and so on. The interval is part of the model; the answer must lie in it.

Then use the previous topic. Find critical points of the objective inside the interval. On a closed interval, compare the objective at the critical points and endpoints. On an open interval, justify that a critical point is the absolute optimum, for example because it is the only critical point and the first-derivative test shows a maximum (or minimum), or because the function is concave down (up) everywhere on the interval.

Finally answer the question that was asked — often the dimensions, not the maximum value — with units, and check that it is sensible (does the box have positive height? is the cost smaller than at the endpoints?).

An example, explained

Largest rectangle with a fixed perimeter

Problem. A rectangle has perimeter 24 m. Find the side lengths giving the largest area, and that area.

  1. Sides x and y with 2x + 2y = 24, so y = 12 − x.

    Constraint.

  2. A(x) = x(12 − x) = 12x − x2, for 0 < x < 12.

    Objective in one variable, with its interval.

  3. A′(x) = 12 − 2x = 0 ⇒ x = 6.

    Critical point, inside the interval.

  4. A″(x) = −2 < 0, so x = 6 gives the maximum.

    Concave down on the whole interval.

Result: A 6 m × 6 m square, area 36 m2.

What it means: For a perimeter of 40 m the same method gives a 10 m × 10 m square of area 100 m2.

Common misunderstandings

  • Misunderstanding: Differentiating before using the constraint (with two variables left).

    Correct idea: Reduce the objective to one variable first.

  • Misunderstanding: Ignoring the feasible interval, or keeping critical points outside it.

    Correct idea: Write the interval and discard infeasible solutions (like x = 6 in the box problem).

  • Misunderstanding: Stopping at f′ = 0 without justifying a maximum or minimum.

    Correct idea: Use the endpoint comparison, the first-derivative test or the second-derivative test.

  • Misunderstanding: Answering with the wrong quantity.

    Correct idea: If the question asks for dimensions, give the dimensions (with units), not just the optimal value.

Applied optimization

Meaning

Optimization turns a real constraint into a one-variable objective, then uses derivative evidence to choose a feasible best value.

Method

Sketch and label variables, write the objective, use constraints to eliminate variables, determine the physical domain, find critical points, compare with boundaries, then translate the winning x back into the requested dimensions or quantity.

Worked reasoning

A 12-by-12 sheet forms an open box by cutting x from each corner. V(x)=x(12−2x)² for 0<x<6. V′=12(x−2)(x−6); the interior maximum is at x=2, giving V=128 cubic units.

Additional worked example

A rectangle has perimeter 20. What dimensions maximize its area?

Let one side be x; the other is 10−x, with 0<x<10. A=x(10−x), and A′=10−2x vanishes at x=5. The maximum is a 5-by-5 square.

Common error. An algebraic critical point outside the feasible domain cannot solve the original problem.

Background: functions and graphs

Review material the Semester 1 topics rely on: domains, function families, trigonometric, exponential and logarithmic functions.

01

Functions and their graphs

Meaning

A function assigns exactly one output to each allowed input. Its domain is the allowed input set; its range is the outputs actually attained. A graph passes the vertical line test precisely when it represents a function of x.

Method

Read a graph in this order: domain, range, intercepts, sign, increasing or decreasing intervals, then symmetry. Compute f(−x): equality with f(x) means even symmetry; equality with −f(x) means odd symmetry. Neither relation may hold. For a formula, exclude zero denominators and negative radicands of even roots.

Worked reasoning

For f(x)=√(4−x²), require 4−x²≥0, so the domain is [−2,2]. Outputs run from 0 to 2. Since f(−x)=f(x), the upper semicircle is even.

Additional worked example

Find the domain and symmetry of g(x)=x/(x²−1).

Exclude x=−1 and x=1. Since g(−x)=−g(x), the function is odd on its symmetric domain.

Common error. A vertical line crossing twice disproves function status; a horizontal line crossing twice does not.

02

Composition of functions

Meaning

Composition feeds the output of one function into another. Order matters, and the domain must survive both stages.

Method

Identify the inner operation first, then the outer operation. For the domain of f∘g, require x in the domain of g and g(x) in the domain of f. To unpack a complicated expression, peel off the outermost action one layer at a time.

Worked reasoning

If f(u)=√u and g(x)=x−3, then (f∘g)(x)=√(x−3), defined for x≥3. But (g∘f)(x)=√x−3, defined for x≥0; the outputs and domains differ.

Additional worked example

Write h(x)=ln(1+x²) as a composition and state its domain.

Take g(x)=1+x² and f(u)=ln u. Then h=f∘g. Because 1+x²>0 for every real x, the domain is all real numbers.

Common error. Do not cancel the distinction between f(g(x)) and g(f(x)); test each domain from inside outward.

20

Hyperbolic and inverse hyperbolic derivatives

Meaning

Hyperbolic functions are built from exponentials. Their derivatives resemble trig derivatives but some signs differ: (cosh x)′=sinh x, without a minus sign.

Method

Apply the basic derivative and then the chain rule. For inverse hyperbolic tangent, use (artanh u)′=u′/(1−u²), valid in the real interval |u|<1. Check the argument domain before evaluating.

Worked reasoning

For y=[artanh(x²)]³ on |x|<1, y′=3[artanh(x²)]²·2x/(1−x⁴).

Additional worked example

Differentiate sinh(3x)+cosh x.

3cosh(3x)+sinh x.

Common error. Do not import the minus sign from the derivative of ordinary cosine into hyperbolic cosine.

26

L’Hôpital’s rule

Meaning

For a quotient with a verified 0/0 or ∞/∞ form, differentiating numerator and denominator separately can reveal its limit, under the rule’s conditions.

Method

Determine the form before applying the rule. Differentiate top and bottom independently, then re-evaluate; repeat only if the new quotient remains indeterminate. Transform products, differences, and variable powers into a quotient or take logarithms before using the rule.

Worked reasoning

lim as x→0 of (eˣ−1)/x is 0/0, then lim eˣ/1=1. This is not a quotient-rule differentiation.

Additional worked example

Evaluate lim as x→∞ of x/eˣ.

It is ∞/∞, so one application gives lim 1/eˣ=0.

Common error. The rule does not apply to a quotient merely because a denominator approaches zero.

29

Newton’s method

Meaning

Newton’s method uses a tangent-line x-intercept to refine a root estimate for f(x)=0.

Method

Choose an initial estimate near the desired root. Evaluate f and f′ at that estimate and iterate. Stop when the change and residual are suitably small. If f′ is zero or very small, or the starting point is poor, the iteration may fail or move to a different root.

Worked reasoning

For f(x)=x²−2 and x₀=1.5, x₁=1.5−(2.25−2)/3=1.41667. One further step gives approximately 1.41422, close to √2.

Additional worked example

Use one Newton step for f(x)=x²−3 from x₀=2.

x₁=2−(4−3)/4=1.75.

Common error. An iteration value is an approximation; check the residual f(xₙ) rather than assuming convergence.

30

Approximate area and distance

Meaning

A rectangle sum approximates accumulated area. With velocity as the height, the sum approximates displacement; absolute velocity approximates distance traveled.

Method

Partition [a,b] into equal widths. Select left endpoints, right endpoints, or midpoints as sample positions; multiply each height by width and add. For an increasing positive function, left sums underestimate and right sums overestimate. A midpoint estimate is often better but is not universally exact.

Worked reasoning

For f(x)=x on [0,2] with two equal rectangles, Δx=1. Left sum is f(0)+f(1)=1; right sum is f(1)+f(2)=3; midpoint sum is f(0.5)+f(1.5)=2.

Additional worked example

Compute L₂ and R₂ for f(x)=x² on [0,2].

With Δx=1, L₂=f(0)+f(1)=1 and R₂=f(1)+f(2)=5.

Common error. Do not omit Δx; summing heights alone has the wrong units.

31

Riemann sums and the fundamental theorem

Meaning

A definite integral is the limit of signed rectangle sums. The fundamental theorem links this accumulation to antiderivatives.

Method

Interpret ∫ as signed area or accumulated change. To evaluate, find an antiderivative F and subtract F(a) from F(b). Reversing bounds changes the sign; adjacent intervals add. If an accumulation function is A(x)=∫ from a to x of f(t)dt, then A′(x)=f(x) where f is continuous.

Worked reasoning

∫ from 0 to 2 of (3x²−1)dx = [x³−x] from 0 to 2 = 6. The integrand may be negative on part of the interval, but the integral is net signed accumulation.

Additional worked example

Evaluate ∫ from 1 to 3 of 2x dx.

An antiderivative is x²; 3²−1²=8.

Common error. A definite integral can be negative; “area” without qualification is not always the same as signed integral.

32

Substitution in integration

Meaning

Substitution reverses the chain rule by replacing a repeated inner expression with a new variable.

Method

Set u equal to the inner expression, compute du, and rewrite the entire integrand. For a definite integral, convert both bounds to u-values or return to x before evaluating, never mix systems. Differentiate an indefinite result to check.

Worked reasoning

∫2x cos(x²)dx: let u=x², du=2x dx. Then ∫cos u du=sin u+C=sin(x²)+C.

Additional worked example

Evaluate ∫ from 0 to 1 of 2x/(1+x²) dx.

Set u=1+x², giving bounds 1 to 2. The integral is ∫ from 1 to 2 of du/u = ln 2.

Common error. Replacing g(x) by u while leaving an unmatched x or dx behind is not a completed substitution.

33

Area between curves

Meaning

Thin strips add vertical or horizontal gaps between boundaries. Geometric area is nonnegative, so a crossing may require splitting an interval.

Method

Find intersections to establish bounds. Decide whether vertical or horizontal strips describe the region more simply. For vertical strips integrate top minus bottom with respect to x; for horizontal strips integrate right minus left with respect to y. Split where the ordering changes.

Worked reasoning

Between y=x and y=x² on [0,1], x≥x², so A=∫₀¹(x−x²)dx=[x²/2−x³/3]₀¹=1/6.

Additional worked example

Find the area enclosed by y=4 and y=x².

Intersections are x=−2 and 2. A=∫₋₂²(4−x²)dx=32/3.

Common error. Integrating one curve alone gives area to the axis, not necessarily area between two curves.

34

Volumes by disks and washers

Meaning

Slices perpendicular to the rotation axis are circles or rings. Each cross-sectional area is π times outer radius squared minus inner radius squared.

Method

Sketch the region and axis. Pick a slice perpendicular to the axis, measure outer and inner radii as distances from the axis, then integrate cross-sectional area across the full solid. A disk is a washer with inner radius zero.

Worked reasoning

Rotate the region under y=x, 0≤x≤2, about the x-axis. Each disk has radius x, so V=π∫₀²x²dx=8π/3.

Additional worked example

Rotate the region between y=2 and y=1, 0≤x≤3, about the x-axis. Find the volume.

Outer radius 2 and inner radius 1 give V=π∫₀³(4−1)dx=9π.

Common error. A radius is distance to the rotation axis, not automatically the displayed function value.

35

Volumes by cylindrical shells

Meaning

Slices parallel to the rotation axis sweep out thin cylindrical shells. Circumference times height times thickness gives each shell’s volume.

Method

Draw a representative strip parallel to the axis. Radius is its distance to the axis; height is upper minus lower or right minus left; thickness fixes whether the integration variable is x or y. Compare with washers and choose the setup with simpler boundaries.

Worked reasoning

Rotate the region under y=x on [0,2] about the y-axis. Vertical strips have radius x and height x, so V=2π∫₀²x²dx=16π/3.

Additional worked example

Rotate the region under y=1 on [0,2] about the y-axis. Use shells.

Radius x, height 1; V=2π∫₀²x dx=4π.

Common error. The shell radius and height are different geometric measurements; do not square the radius as in a disk.

36

Average value of a function

Meaning

Average value is total signed accumulation divided by interval length. For a continuous function, some point in the interval attains this average.

Method

Compute the definite integral, then divide by b−a. Keep it distinct from the endpoint average [f(a)+f(b)]/2, which is generally different. If the function represents a rate, the average is a rate with the original output units.

Worked reasoning

For f(x)=x³ on [0,2], the integral is [x⁴/4]₀²=4. Dividing by interval length 2 gives average value 2.

Additional worked example

Find the average value of sin x on [0,π].

∫₀^π sin x dx=2, so the average is 2/π.

Common error. The integral itself is accumulated total; the average requires division by interval length.

38

Slope fields

Meaning

A differential equation supplies a slope at each point where its right-hand side is defined. A slope field shows short line segments with those slopes.

Method

Evaluate F at a grid of points and draw a short segment at each, without connecting points automatically. A solution curve follows the segments from its initial condition. Look for zero-slope lines and undefined regions before sketching.

Worked reasoning

For y′=x, all points with the same x share the same slope. Integrating gives y=x²/2+C; through (0,2), C=2.

Additional worked example

For y′=y−x, what is the slope along y=x?

It is zero because y−x=0 along that line; field marks there are horizontal.

Common error. A field segment is local slope information, not a straight solution line through the whole plane.

39

Separable equations and exponential change

Meaning

A separable equation factors into a y-part and an x-part. When growth rate is proportional to the current amount, solutions are exponential.

Method

For y′=ky, write dy/y=k dx on a region where y≠0, integrate to ln|y|=kx+C, and recover y=Ce^(kx). Include the zero solution, which division by y temporarily omits. Apply the initial condition; a positive k grows and negative k decays.

Worked reasoning

For y′=−0.03y with y(0)=500, y=500e^(−0.03x). Its half-life solves 1/2=e^(−0.03x), so x=ln2/0.03≈23.1 time units.

Additional worked example

Solve y′=0.05y, y(0)=100, and find doubling time.

y=100e^(0.05x). Doubling requires 2=e^(0.05x), so x=ln2/0.05≈13.9 time units.

Common error. Dividing by y without restoring y=0 can discard a valid solution.

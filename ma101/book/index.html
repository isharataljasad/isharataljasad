Limits

A limit describes the value a function approaches near a point, not the value at the point.

Compare this topic:BookPearsonEducatorFull guide

Definitions

Limit
We write limx→a f(x) = L when the values f(x) can be made as close to L as we like by taking x sufficiently close to a, with x ≠ a. The value f(a), if it exists, plays no part.
One-sided limits
limx→a− f(x) uses only inputs x < a; limx→a+ f(x) uses only x > a. The two-sided limit equals L exactly when both one-sided limits equal L.
Indeterminate form
An expression such as 0 / 0 obtained by direct substitution. It tells you that more work is needed; different functions giving 0 / 0 can have completely different limits.
Limit at infinity
limx→∞ f(x) = L means f(x) gets arbitrarily close to L as x grows without bound. The line y = L is then a horizontal asymptote of the graph.
Infinite limit
limx→a f(x) = ∞ means f(x) grows without bound near a. The limit does not exist as a number; writing ∞ describes how it fails. The line x = a is a vertical asymptote.
Symbols, meanings and units
SymbolMeaningUnit
x → ax approaches a, taking values near a but never equal to asame units as x
x → a−, x → a+approach from the left (x < a) or from the right (x > a)—
Lthe limiting value of f(x)same units as f(x)
ε, δepsilon: allowed error in the output; delta: allowed distance of the input from aoutput units, input units

Formulas and their conditions

Existence test

limx→a f(x) = L ⇔ limx→a− f(x) = L and limx→a+ f(x) = L

Conditions and limits: Always. If the one-sided limits differ, or either fails to exist, the two-sided limit does not exist.

Limit laws

lim (f ± g) = lim f ± lim g; lim (f·g) = (lim f)(lim g); lim f / g = lim f / lim g

Conditions and limits: Valid when lim f and lim g exist (as finite numbers), and for the quotient only when lim g ≠ 0.

Direct substitution

limx→a p(x) = p(a)

Conditions and limits: For polynomials at every a; for rational functions p / q wherever q(a) ≠ 0. Also for √x, sin x, cos x, ex at points of their domain.

Fundamental trigonometric limit

limx→0 sin x / x = 1

Conditions and limits: x must be measured in radians. In degrees the limit is π/180, not 1.

Squeeze theorem

If g(x) ≤ f(x) ≤ h(x) near a and lim g = lim h = L, then lim f = L

Conditions and limits: The inequalities must hold for all x near a (except possibly at a).

Rational functions at infinity

limx→∞ anxn + … / bmxm + … = 0 if n < m; an / bm if n = m; ±∞ if n > m

Conditions and limits: Divide numerator and denominator by the highest power of x in the denominator. For n > m the sign depends on the leading coefficients and on whether x → +∞ or −∞.

Why cancelling a factor that is zero at the point is allowed

Cancelling (x − 3) looks like dividing by zero at x = 3. The definition of a limit is what makes it legitimate.

  1. Factor: x2 − 9 / x − 3 = (x − 3)(x + 3) / x − 3.

    Factoring exposes the factor that makes both numerator and denominator zero.

  2. The limit only uses inputs with x ≠ 3.

    By definition, limx→3 looks at x near 3 and excludes x = 3 itself.

  3. For x ≠ 3, x − 3 ≠ 0, so the factor cancels: the expression equals x + 3.

    Dividing by a non-zero number is always allowed.

  4. The two functions agree at every input the limit uses, so they have the same limit: limx→3 (x + 3) = 6.

    x + 3 is a polynomial, so direct substitution is valid for it.

The original expression is still undefined at x = 3. We have found its limit, not its value.

The precise (ε–δ) meaning of a limit

limx→a f(x) = L means: for every tolerance ε > 0 on the output there is a distance δ > 0 such that 0 < |x − a| < δ guarantees |f(x) − L| < ε. In words, however strict the output tolerance, we can meet it by keeping the input close enough to a.

Example: for f(x) = 2x + 1 at a = 3, L = 7. Then |f(x) − 7| = |2x − 6| = 2|x − 3|. To make this less than ε we need |x − 3| < ε/2, so δ = ε/2 works. For ε = 0.1, δ = 0.05. The factor 2 is the slope: the function doubles input errors, so the input tolerance must be half the output tolerance.

Worked example

Factoring a 0/0 form

Problem. Find limx→2 x2 − 4 / x − 2.

  1. Substitute x = 2: numerator 4 − 4 = 0, denominator 2 − 2 = 0. The form is 0 / 0.

    Substitution first tells us whether more work is needed.

  2. Factor the numerator: x2 − 4 = (x − 2)(x + 2).

    Zero in both parts means (x − 2) is a common factor.

  3. Cancel (x − 2), valid because x ≠ 2 inside the limit: the expression becomes x + 2.

    The limit never uses x = 2 itself.

  4. Substitute into the polynomial: 2 + 2 = 4.

    Direct substitution is valid for polynomials.

Result: limx→2 x2 − 4 / x − 2 = 4.

What it means: The graph is the line y = x + 2 with a hole at (2, 4).

Scope

  • The ε–δ definition is explained with a linear example; general ε–δ proofs belong to real analysis.
  • L’Hôpital’s rule is not used here. It needs derivatives and has its own conditions; check whether your lecturer includes it in MA 101.

06

Why limits connect rates and area

Principle

Calculus studies what happens as a step becomes arbitrarily small. A shrinking secant interval leads to an instantaneous rate; thinner rectangles lead to exact accumulated area.

Why and when

A limit concerns nearby values, not necessarily the value at the target input. The same limiting idea supports the two major operations of calculus: differentiation and integration.

Worked solution

For f(x)=x² at x=2, a step h gives average rate [(2+h)²−4]/h=4+h. As h approaches zero, the rate approaches 4.

Additional worked example

For f(x)=x³ at x=1, simplify [f(1+h)−f(1)]/h and find its limit.

The quotient is 3+3h+h²; the limit is 3.

Common trap. Cancel h only after expanding the numerator, and do not substitute h=0 into an unsimplified 0/0 form.

07

One-sided limits and failure to agree

Principle

A finite two-sided limit exists only if the left and right approaches settle at the same number. A point can have a different assigned value without changing that approach.

Why and when

Trace each side separately on a graph or in a piecewise rule. Distinguish a finite limit from unbounded behavior, a jump, and persistent oscillation.

Worked solution

Let f(x)=x+2 for x<1 and f(x)=x² for x≥1. The left limit is 3, the right limit is 1, and f(1)=1. Therefore the two-sided limit does not exist.

Additional worked example

Let g(x)=x² for x≠2 and g(2)=9. Find the limit as x approaches 2 and g(2).

The limit is 4; the assigned value is 9. Changing one point does not alter the values around it.

Common trap. Substitution gives the point value only after continuity has been established.

08

Limit laws and algebraic repair

Principle

Limit laws permit arithmetic with finite limits. Direct substitution is valid for continuous expressions where defined. The indeterminate form 0/0 signals that more analysis is needed.

Why and when

Try substitution first. If 0/0 appears, factor, combine fractions, or rationalize. Simplify on x≠c before taking the limit; the function need not be defined at c.

Worked solution

lim as x→3 of (x²−9)/(x−3) equals lim(x+3)=6 because x²−9=(x−3)(x+3) away from 3.

Additional worked example

Find lim as x→0 of [√(1+2x)−1]/x.

Multiply by the conjugate: 2/[√(1+2x)+1], which tends to 1.

Common trap. 0/0 is neither zero nor a limit value; it is a prompt to transform the expression.

10

Precise control with epsilon and delta

Principle

The formal limit statement says every requested output tolerance ε>0 can be met by choosing a sufficiently small input tolerance δ>0. The puncture 0<|x−a| leaves f(a) irrelevant.

Why and when

For a linear function, bound the output error by a constant times |x−a|, then choose δ in terms of ε. For more complex functions, also restrict δ so factors stay bounded.

Worked solution

For f(x)=3x+2 at a=1, L=5 and |f(x)−5|=3|x−1|. Given any ε>0, choose δ=ε/3; then 0<|x−1|<δ gives |f(x)−5|<ε.

Additional worked example

Choose δ proving lim as x→2 of (4x−1) equals 7.

Since |(4x−1)−7|=4|x−2|, δ=ε/4 works for every ε>0.

Common trap. δ must be chosen after ε is given, and the implication must cover every allowed x near a.

Continuity

A function is continuous at a point when its limit there exists and equals its value: no holes, jumps or breaks.

Compare this topic:BookPearsonEducatorFull guide

Definitions

Continuous at a point
f is continuous at x = a when (1) f(a) is defined, (2) limx→a f(x) exists, and (3) limx→a f(x) = f(a).
Continuous on an interval
f is continuous at every point of an open interval (a, b). On a closed interval [a, b] we also need one-sided continuity at the ends: limx→a+ f(x) = f(a) and limx→b− f(x) = f(b).
Removable discontinuity
The limit at a exists, but f(a) is undefined or differs from it. Defining f(a) to be the limit removes the discontinuity.
Jump discontinuity
Both one-sided limits exist but are different. The size of the jump is |right limit − left limit|.
Infinite discontinuity
At least one one-sided limit is +∞ or −∞. The graph has a vertical asymptote at x = a.
Symbols, meanings and units
SymbolMeaningUnit
f(a)the value of f at a (must exist for continuity)output units
limx→a± f(x)one-sided limits from the right (+) or left (−)output units
[a, b], (a, b)closed interval (endpoints included), open interval (endpoints excluded)input units

Formulas and their conditions

Continuity test

limx→a f(x) = f(a)

Conditions and limits: All three parts must be checked: the value exists, the limit exists, and they are equal.

Continuity of combinations

f ± g, f·g, f / g, f(g(x)) are continuous

Conditions and limits: When f and g are continuous at the relevant points; the quotient needs g(a) ≠ 0; the composition needs g continuous at a and f continuous at g(a).

Intermediate Value Theorem (IVT)

f continuous on [a, b] and N between f(a) and f(b) ⇒ f(c) = N for some c in (a, b)

Conditions and limits: Continuity on the whole closed interval is essential. The theorem guarantees that c exists; it does not say where, or that there is only one.

Why the IVT needs continuity

Consider f(x) = −1 for x < 0 and f(x) = 1 for x ≥ 0, on [−1, 1].

  1. f(−1) = −1 < 0 and f(1) = 1 > 0, so the signs are opposite.

    This is the situation in which the IVT would promise a zero.

  2. Yet f(x) is never 0: it only takes the values −1 and 1.

    The graph jumps over the axis at x = 0.

  3. The hypothesis fails: f has a jump discontinuity at 0.

    Without continuity the conclusion of the theorem can be false.

A theorem’s conclusion is only guaranteed when its conditions are checked. That is why every IVT argument starts with “f is continuous on [a, b] because …”.

Worked example

Repair a removable discontinuity

Problem. f(x) = 2x + 1 for x ≠ 2. What value of f(2) makes f continuous at 2?

  1. limx→2 (2x + 1) = 5.

    2x + 1 is a polynomial, so substitute x = 2.

  2. Continuity needs f(2) = limx→2 f(x).

    The third condition of the definition.

Result: Define f(2) = 5.

What it means: Filling the hole with the limiting value makes the graph an unbroken line.

Scope

  • Continuity is treated for functions of one real variable. Uniform continuity and ε–δ proofs of continuity are beyond this course level.
  • The Extreme Value Theorem (a continuous function on [a, b] has a maximum and a minimum) is used in the “Extrema and curve shape” topic.

09

Continuity and guaranteed crossings

Principle

Continuity requires a defined point value, an existing two-sided limit, and agreement between them. On a closed interval, continuity also guarantees every intermediate output between the endpoint outputs occurs somewhere.

Why and when

At a piecewise join, compute both side limits and the assigned value. For an existence question, the intermediate value theorem requires continuity on the whole interval.

Worked solution

Let f(x)=ax+1 for x<2 and f(x)=x² for x≥2. Matching the left limit 2a+1 with f(2)=4 gives a=3/2.

Additional worked example

Explain why x³+x−1 has a root between 0 and 1.

It is a continuous polynomial; values at 0 and 1 are −1 and 1. Since zero lies between those values, a root lies in (0,1).

Common trap. The theorem guarantees existence, not a formula for the root.

Derivative as a rate

The derivative is the instantaneous rate of change: the limit of average rates, and the slope of the tangent line.

Compare this topic:BookPearsonEducatorFull guide

Definitions

Average rate of change
Over [a, a + h]: f(a + h) − f(a) / h, the slope of the secant line through (a, f(a)) and (a + h, f(a + h)).
Derivative at a point
f′(a) = limh→0 f(a + h) − f(a) / h, provided the limit exists. It is the instantaneous rate of change of f at a and the slope of the tangent line there.
Tangent line
The line through (a, f(a)) with slope f′(a): y = f(a) + f′(a)(x − a).
Derivative function
f′(x) = limh→0 f(x + h) − f(x) / h for each x where the limit exists. Other notations: dy / dx, df / dx, y′.
Differentiable
f is differentiable at a if f′(a) exists. Differentiability fails at corners, cusps, vertical tangents and discontinuities.
Symbols, meanings and units
SymbolMeaningUnit
h (or Δx)a small change in the inputinput units
Δy = f(a + h) − f(a)the corresponding change in the outputoutput units
f′(a), dy / dxderivative (instantaneous rate of change)output units ÷ input units
v = s′(t)velocity as the derivative of positionm/s if s in m and t in s

Formulas and their conditions

Definition of the derivative

f′(a) = limh→0 f(a + h) − f(a) / h

Conditions and limits: The limit must exist (the same from both sides). If the left and right limits differ, as at a corner, f is not differentiable at a.

Alternative form

f′(a) = limx→a f(x) − f(a) / x − a

Conditions and limits: Equivalent to the first form (put x = a + h).

Tangent line

y = f(a) + f′(a)(x − a)

Conditions and limits: Requires f to be differentiable at a. It uses both the point value f(a) and the slope f′(a).

Differentiable ⇒ continuous

f′(a) exists ⇒ limx→a f(x) = f(a)

Conditions and limits: The converse is false: |x| is continuous at 0 but not differentiable there.

Derivative of f(x) = x² from the definition

This is the model for every first-principles calculation.

  1. Difference quotient: (x + h)2 − x2 / h.

    Substitute x + h and x into f.

  2. Expand: x2 + 2xh + h2 − x2 / h = 2xh + h2 / h.

    The x2 terms cancel; every remaining term contains h.

  3. Cancel h (allowed because h ≠ 0 inside the limit): 2x + h.

    This removes the 0/0 form.

  4. Let h → 0: f′(x) = 2x.

    2x + h is a polynomial in h, so substitute h = 0.

So the slope of y = x² at x = 1 is 2, at x = 3 is 6, and at x = −2 is −4. The slope changes from point to point, which is why the derivative is a function.

Worked example

Derivative at a point from the definition

Problem. For f(x) = x2 + 3x, find f′(2) from the definition.

  1. f(2 + h) = (2 + h)2 + 3(2 + h) = 4 + 4h + h2 + 6 + 3h = 10 + 7h + h2.

    Replace x by 2 + h and expand.

  2. f(2) = 4 + 6 = 10, so f(2 + h) − f(2) = 7h + h2.

    The constant terms cancel.

  3. 7h + h2 / h = 7 + h for h ≠ 0.

    Cancel the common factor h.

  4. Let h → 0: f′(2) = 7.

    Substitute h = 0 in 7 + h.

Result: f′(2) = 7.

What it means: Near x = 2 the output increases about 7 units for each unit increase in x.

Scope

  • Here derivatives are computed from the definition. The faster rules (power, product, quotient, chain) are in the next topic.
  • One-variable functions only; partial derivatives belong to later courses.

11

Derivative from the tangent limit

Principle

The derivative is the limiting slope of secant lines and the instantaneous rate of output change. The tangent line at a uses both that slope and the point (a,f(a)).

Why and when

Form the difference quotient, simplify before taking the limit, then use point-slope form. Units of f′ are output units per input unit.

Worked solution

For f(x)=x²+1, [(a+h)²+1−(a²+1)]/h=2a+h; hence f′(a)=2a. At a=2, point (2,5), the tangent is y−5=4(x−2).

Additional worked example

Find the tangent line to f(x)=x³ at x=1.

f(1)=1 and f′(1)=3, so y−1=3(x−1).

Common trap. A tangent slope alone is not a line; include the point on the original graph.

12

Derivative as a function and differentiability

Principle

The derivative function records tangent slope at each input where that slope exists. Its sign describes direction. Differentiability implies continuity, but a continuous corner can still lack a derivative.

Why and when

Compare one-sided slopes at corners, cusps, and vertical tangents. At a jump there can be no derivative. A graph of f′ is above the axis where f rises and below it where f falls.

Worked solution

For f(x)=|x|, the left slope at zero is −1 and the right slope is +1. The function is continuous there, but its derivative is undefined at zero.

Additional worked example

For f(x)=x³−3x, where is f increasing?

f′(x)=3x²−3>0 for x<−1 and x>1, so f rises on (−∞,−1) and (1,∞).

Common trap. A zero derivative does not itself prove a maximum or minimum; check signs.

14

Rates, velocity, and acceleration

Principle

A derivative can represent any instantaneous rate. For position, velocity is signed and speed is its magnitude; acceleration is the rate of velocity change.

Why and when

Find turning times by solving v(t)=0 and checking sign changes. Displacement is final minus initial position, whereas total distance adds the magnitudes of each directional segment.

Worked solution

For s(t)=t²−4t on [0,5], v=2t−4 changes sign at t=2. Positions are 0,−4,5. Displacement is 5; distance is 4+9=13.

Additional worked example

For s(t)=t²−2t on [0,3], find displacement and distance.

The turning time is t=1. Positions 0,−1,3 give displacement 3 and distance 1+4=5.

Common trap. The difference of endpoint positions misses a reversal of direction.

Differentiation rules

Rules that give derivatives quickly and reliably: power, sum, product, quotient and chain rules, with the derivatives of trigonometric, exponential and logarithmic functions.

Compare this topic:BookPearsonEducatorFull guide

Definitions

Power rule
d / dx xn = nxn−1 for any constant n (for non-integer n, on x > 0 where xn is defined).
Linearity
(cf)′ = cf′ and (f ± g)′ = f′ ± g′: constants factor out and sums split.
Product rule
(fg)′ = f′g + fg′.
Quotient rule
(f/g)′ = f′g − fg′ / g2, wherever g ≠ 0.
Chain rule
d / dx f(g(x)) = f′(g(x))·g′(x). In Leibniz form, with y = f(u) and u = g(x): dy / dx = dy / du·du / dx.
Higher derivatives
f″ is the derivative of f′; it measures how the rate itself changes. If s(t) is position, s′ = v is velocity and s″ = a is acceleration.
Implicit differentiation
When y is defined by an equation such as x2 + y2 = 25, differentiate both sides with respect to x, treating y as a function of x (so y2 gives 2y·y′), then solve for y′.
Symbols, meanings and units
SymbolMeaningUnit
f′, df / dx, d / dxderivative with respect to xoutput units ÷ x units
f″, d2f / dx2second derivativeoutput units ÷ (x units)²
uthe inside function in the chain rule—

Formulas and their conditions

Constants and powers

(c)′ = 0; (xn)′ = nxn−1; (cf)′ = cf′; (f ± g)′ = f′ ± g′

Conditions and limits: n any real constant; for non-integer n restrict to x > 0 (and check endpoints separately).

Product and quotient

(fg)′ = f′g + fg′; (f / g)′ = f′g − fg′ / g2

Conditions and limits: f and g differentiable; the quotient needs g(x) ≠ 0.

Chain rule

[f(g(x))]′ = f′(g(x))·g′(x)

Conditions and limits: g differentiable at x and f differentiable at g(x).

Trigonometric

(sin x)′ = cos x; (cos x)′ = −sin x; (tan x)′ = sec2 x

Conditions and limits: x in radians; tan x needs cos x ≠ 0.

Exponential and logarithmic

(ex)′ = ex; (ax)′ = ax ln a; (ln x)′ = 1 / x; (ln|x|)′ = 1 / x

Conditions and limits: a > 0 constant; ln x needs x > 0, ln|x| needs x ≠ 0.

Chain-rule versions

(un)′ = nun−1u′; (sin u)′ = cos u·u′; (eu)′ = euu′; (ln u)′ = u′ / u

Conditions and limits: u is any differentiable inside function (ln u needs u > 0).

Inverse trigonometric

(arcsin x)′ = 1 / √1 − x2; (arctan x)′ = 1 / 1 + x2

Conditions and limits: arcsin: |x| < 1. arctan: all real x. Note arcsin x is the inverse function, not 1/sin x.

Why the product rule has two terms

Think of a rectangle with sides f(x) and g(x), so its area is A = fg. Increase x by h.

  1. The sides become f + Δf and g + Δg. The new area is fg + Δf·g + f·Δg + Δf·Δg.

    Expand (f + Δf)(g + Δg).

  2. The change in area is ΔA = Δf·g + f·Δg + Δf·Δg.

    Subtract the original area fg.

  3. Divide by h: ΔA / h = Δf / hg + fΔg / h + Δf / hΔg.

    This is the difference quotient of the product.

  4. Let h → 0: Δf/h → f′, Δg/h → g′ and Δg → 0 (g is continuous), so the last term vanishes.

    Two strips survive; the tiny corner does not.

Hence (fg)′ = f′g + fg′: each factor’s change, multiplied by the other factor.

Worked example

Power and sum rules

Problem. Differentiate y = 4x3 − 6 / x + 2√x.

  1. Rewrite: y = 4x3 − 6x−1 + 2x1/2.

    Every term becomes a power of x.

  2. Differentiate term by term: 12x2 − 6(−1)x−2 + 2·1 / 2x−1/2.

    Bring down each exponent and reduce it by one.

Result: y′ = 12x2 + 6 / x2 + 1 / √x (for x > 0).

What it means: The domain x > 0 comes from √x in the original function and 1/√x in the derivative.

Scope

  • Derivatives of hyperbolic functions are not included; check your outline.
  • The rules assume each function is differentiable where it is used; at corners, cusps or outside the domain they do not apply.
  • Logarithmic differentiation (for example of xx) is shown in the collection notes below; xx is neither a power function nor an exponential with constant base.

13

Power, product, and quotient rules

Principle

Differentiate sums term by term. A product changes through either factor; a quotient’s derivative has a denominator squared and a subtraction in the numerator.

Why and when

Mark each factor before differentiating. For quotients, preserve parentheses around both numerator products and state where the denominator is nonzero.

Worked solution

For y=(x²+1)/(x−1), y′=[2x(x−1)−(x²+1)]/(x−1)²=(x²−2x−1)/(x−1)², x≠1.

Additional worked example

Differentiate y=x²(x³+1).

y′=2x(x³+1)+3x⁴=5x⁴+2x. Expanding first to x⁵+x² gives the same result.

Common trap. The derivative of uv is not u′v′.

15

Trigonometric derivatives in radians

Principle

The standard trigonometric derivative rules use radian measure. Combining them with the chain rule handles oscillations whose angle changes at a different rate.

Why and when

Differentiate the outer trigonometric function, keep the original argument, then multiply by the derivative of the argument. Check the negative sign for cosine.

Worked solution

For y=sin(3x²), the outer derivative is cos(3x²) and the inner rate is 6x, so y′=6x cos(3x²).

Additional worked example

Differentiate y=cos(2x−1)+tan x.

y′=−2sin(2x−1)+sec²x.

Common trap. If the angle were in degrees, these derivative formulas would need an extra conversion factor.

16

The chain rule for nested change

Principle

When an output depends on an intermediate quantity, rates multiply. The outer derivative is evaluated at the inner expression, not at x alone.

Why and when

Name the inner function u=g(x). Differentiate f(u) with respect to u and u with respect to x, then multiply. For several layers, repeat from outside inward.

Worked solution

For y=(1+x²)⁵, set u=1+x². Then dy/du=5u⁴ and du/dx=2x, so y′=10x(1+x²)⁴.

Additional worked example

Differentiate y=√(1+3x²).

y′=(1/2)(1+3x²)^(−1/2)·6x=3x/√(1+3x²).

Common trap. The missing inner derivative is the most common source of a wrong chain-rule answer.

17

Derivatives of inverses

Principle

An inverse reverses the mapping, so a small output change of f becomes an input change of f⁻¹. The reciprocal slope rule requires a nonzero original derivative at the matching point.

Why and when

Find the point on the original graph corresponding to the inverse input, evaluate f′ there, then take the reciprocal. For inverse trig functions, use their principal branches.

Worked solution

Why the circle’s area grows faster when the circle is larger

A circular oil spill has A = πr2. Differentiate with respect to t.

  1. dA / dt = 2πrdr / dt.

    Chain rule: r depends on t.

  2. 2πr is the circumference.

    A thin ring of width Δr added around the edge has area ≈ (circumference)·Δr.

Worked example

The sliding ladder

Problem. A 5 m ladder leans against a wall. Its foot slides away at 0.5 m/s. How fast is the top sliding down when the foot is 3 m from the wall?

    Pythagoras holds at every instant; the length 5 m is constant.

  2. Differentiate: 2xdx / dt + 2ydy / dt = 0.

    Both x and y depend on t.

  3. At the instant: x = 3, so y = √25 − 9 = 4. Given dx / dt = 0.5.

    Use the original equation to find y.

  4. 2(3)(0.5) + 2(4)dy / dt = 0 ⇒ dy / dt = −3 / 8 = −0.375.

    Solve for the unknown rate.

Definitions

Linearisation
L(x) = f(a) + f′(a)(x − a), the tangent-line function at a. For x near a, f(x) ≈ L(x).

dx is an independent small change in x; dy = f′(x) dx is the corresponding change along the tangent line.

Formulas and their conditions

f(x) ≈ L(x) = f(a) + f′(a)(x − a)

Conditions and limits: f differentiable at a, and x close to a. Accuracy depends on how close x is and how much the graph curves.

Differential

dy = f′(x) dx, Δy ≈ dy

Conditions and limits: dx small. The approximation Δy ≈ dy improves as dx → 0.

Conditions and limits: Follows from dQ = nkxn−1dx. A 1% error in a radius gives about 2% error in an area and 3% in a volume.

Where (1 + x)ⁿ ≈ 1 + nx comes from

Linearise f(x) = (1 + x)n at a = 0.

  1. f(0) = 1.

    Base value.

  2. f′(x) = n(1 + x)n−1, so f′(0) = n.

    Chain rule.

  3. L(x) = 1 + n(x − 0) = 1 + nx.

    Tangent line at 0.

Example: √1.02 = (1 + 0.02)1/2 ≈ 1 + 0.01 = 1.01 (the true value is 1.00995…).

Newton’s method (check whether your outline includes it)

Newton’s method uses linearisation to solve f(x) = 0. From a guess xn, follow the tangent line to where it crosses the x-axis: xn+1 = xn − f(xn) / f′(xn).

Example: for f(x) = x2 − 2 (root √2), start at x0 = 1. Then x1 = 1 − −1 / 2 = 1.5, x2 = 1.5 − 0.25 / 3 ≈ 1.41667, x3 ≈ 1.414216. The true value is 1.414214. The method fails if f′(xn) = 0 or if the starting guess is poor.

Worked example

Estimate a square root

Problem. Use a linear approximation to estimate √4.08.

  1. f(x) = √x, a = 4: f(4) = 2.

    4 is close to 4.08 and has an exact root.

  2. f′(x) = 1 / 2√x, so f′(4) = 1 / 4.

    Power rule with exponent 1/2.

  3. L(x) = 2 + 1 / 4(x − 4).

    Tangent line at 4.

  4. L(4.08) = 2 + 0.08 / 4 = 2.02.

    Substitute x = 4.08.

Result: √4.08 ≈ 2.02.

What it means: The true value is 2.019901…, so the error is about 0.0001. The estimate is slightly high because √x is concave down.

Rolle and Mean Value Theorems

If a smooth function goes from one value to another, somewhere its instantaneous rate equals its average rate.

Compare this topic:BookPearsonEducatorFull guide

Definitions

Rolle’s theorem
If f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b), then there is at least one c in (a, b) with f′(c) = 0.
Mean Value Theorem
If f is continuous on [a, b] and differentiable on (a, b), then there is at least one c in (a, b) with f′(c) = f(b) − f(a) / b − a.
Hypotheses
The conditions of a theorem (here: continuity on [a, b], differentiability on (a, b), and for Rolle f(a) = f(b)). They must be checked before the conclusion is used.
Symbols, meanings and units
SymbolMeaningUnit
[a, b]closed interval, endpoints includedinput units
(a, b)open interval, endpoints excluded; c must lie hereinput units

Formulas and their conditions

Mean Value Theorem

f′(c) = f(b) − f(a) / b − a for some c in (a, b)

Conditions and limits: f continuous on [a, b] and differentiable on (a, b).

Rolle’s theorem

f(a) = f(b) ⇒ f′(c) = 0 for some c in (a, b)

Conditions and limits: Same hypotheses plus equal endpoint values.

Consequences

f′ > 0 on (a, b) ⇒ f increasing; f′ < 0 ⇒ decreasing; f′ = 0 ⇒ f constant

Conditions and limits: On an interval (not across a gap in the domain).

Bounding change

|f(b) − f(a)| ≤ M|b − a| if |f′(x)| ≤ M on (a, b)

Conditions and limits: f satisfies the MVT hypotheses on [a, b].

Why f′ > 0 on an interval means f is increasing

Take any two points x1 < x2 in the interval.

  1. The MVT on [x1, x2] gives c with f(x2) − f(x1) = f′(c)(x2 − x1).

    Rearranged form of the theorem; the hypotheses hold because f is differentiable on the interval.

  2. f′(c) > 0 and x2 − x1 > 0, so the right side is positive.

    A product of positives is positive.

  3. Therefore f(x2) > f(x1).

    This is what “increasing” means.

The first-derivative test used for curve sketching rests on this argument.

Worked example

Find the MVT point for a parabola

Problem. For f(x) = x2 on [0, 4], find all c guaranteed by the Mean Value Theorem.

  1. f is a polynomial: continuous on [0, 4] and differentiable on (0, 4).

    Hypotheses checked.

  2. Secant slope: 16 − 0 / 4 − 0 = 4.

    Average rate of change.

  3. f′(c) = 2c = 4 ⇒ c = 2.

    Solve f′(c) = secant slope.

  4. 2 lies in (0, 4).

    c must be strictly inside the interval.

Result: c = 2.

What it means: For any parabola, the MVT point is the midpoint of the interval.

  • The Cauchy (generalised) Mean Value Theorem is not included.

f(c) is a local maximum if f(c) ≥ f(x) for all x near c (local minimum: ≤).

First-derivative test

f′: + → − at c ⇒ local max; − → + ⇒ local min; no sign change ⇒ neither

Second-derivative test

f′(c) = 0 and f″(c) > 0 ⇒ local min; f″(c) < 0 ⇒ local max

Conditions and limits: Needs f′(c) = 0 (not just “undefined”). If f″(c) = 0 the test is inconclusive.

Why f″ = 0 does not always give an inflection point

Consider f(x) = x4.

  1. f″(x) = 12x2, so f″(0) = 0.

    A candidate for inflection.

  2. But f″(x) = 12x2 > 0 on both sides of 0.

    The concavity does not change: the graph is a cup on both sides.

  3. So (0, 0) is not an inflection point; it is actually a minimum.

    An inflection point needs a change of sign.

Always check the sign of f″ on both sides, just as the first-derivative test checks the sign of f′.

Worked example

Locate a minimum

Problem. Find the minimum of f(x) = x2 − 6x.

  1. f′(x) = 2x − 6 = 0 ⇒ x = 3.

    The only critical point.

  2. f″(x) = 2 > 0.

    Concave up everywhere.

  3. f(3) = 9 − 18 = −9.

    Evaluate at the critical point.

Result: Minimum value −9 at x = 3 (the vertex).

Why a square gives the largest rectangle with a fixed perimeter

01

Functions and their allowed inputs

Principle

A function gives one output for each allowed input. The domain is the set of allowed inputs; the range is the outputs it actually reaches. A graph passes the vertical-line test exactly when it represents a function.

Why and when

A formula can fail because a denominator is zero, an even root has a negative radicand, or a logarithm has a nonpositive argument. For a piecewise definition, the inequality attached to each branch decides the value at a boundary.

Worked solution

For f(x)=√(x+3)/(x−2), the radicand requires x≥−3 and the denominator excludes 2. Thus the domain is [−3,2)∪(2,∞). The function is defined at −3, where f(−3)=0.

Additional worked example

Find the domain of g(x)=ln(4−x)/(x+1).

The logarithm needs 4−x>0, so x<4. Also x≠−1. The domain is (−∞,−1)∪(−1,4).

Common trap. An equality is allowed for an even root but never for a logarithm argument of zero.

02

Function families and transformations

Principle

Linear, polynomial, rational, radical, exponential, and logarithmic functions have different characteristic shapes and restrictions. A transformation is easiest to verify by tracking a known point through the input and output changes.

Why and when

Outside changes act on outputs: a scales and possibly reflects, k shifts vertically. Inside changes act on inputs: h shifts the graph horizontally and b changes horizontal scale by 1/|b|.

Worked solution

From f(x)=x², g(x)=−2(x−3)²+1 has vertex (3,1), opens downward, and is twice as steep in output. The domain is all real numbers and the range is (−∞,1].

Additional worked example

For g(x)=√(x+4)−2, give its starting point, domain, and range.

The parent graph √x moves left 4 and down 2. Start (−4,−2); domain [−4,∞); range [−2,∞).

Common trap. An inside +4 moves the graph left, not right; test the input that makes the radicand zero.

Angles, unit circle, and periodic graphs

Principle

Radian measure links an angle to arc length. Sine and cosine are unit-circle coordinates; identities follow from the circle equation. A sine or cosine graph repeats after a full turn.

Why and when

Determine reference angle and quadrant before signs. For y=A sin(B(x−h))+k, amplitude is |A|, midline is y=k, and period is 2π/|B|. These statements use radians.

For y=3cos(2x)−1, amplitude is 3, period is π, and midline is y=−1. The maximum is 2 at x=0; a minimum −4 occurs at x=π/2.

If sin θ=5/13 and θ is in quadrant II, find cos θ and tan θ.

Inverse functions and restricted branches

Principle

An inverse reverses input and output. It exists as a function only when each output of the original has one input. Graphically, a horizontal line must meet the original graph no more than once.

Why and when

To find an inverse, write y=f(x), solve for x, then exchange x and y. Preserve the original domain and range as the inverse range and domain. Trigonometric inverses require restricted principal branches.

Worked solution

For f(x)=2x−5, solve y=2x−5 to get x=(y+5)/2. Hence f⁻¹(x)=(x+5)/2. For x², first restrict to x≥0 if the intended inverse is √x.

Additional worked example

Find the inverse of f(x)=√(x−1), x≥1, including its domain.

y=√(x−1) gives x=y²+1. Thus f⁻¹(x)=x²+1 with domain x≥0, the range of f.

Common trap. An inverse relation can fail to be a function if the original is not one-to-one.

05

Exponential and logarithmic models

Principle

The variable is in the exponent of an exponential function. A logarithm is its inverse and asks which exponent produced a positive input. The number e is the natural base for calculus.

Why and when

Use log laws only where each argument is positive. To solve an exponential equation, isolate the powered expression and take a logarithm; to solve a log equation, invert and check its domain.

Worked solution

Solve ln(x−1)+ln(x+1)=ln 8. The domain is x>1. Combining logs gives x²−1=8, so x=3 or −3; only x=3 is allowed.

Additional worked example

Solve e^(2x)=7 for x.

Taking natural logarithms gives 2x=ln 7, so x=(ln 7)/2.

Common trap. Do not accept an algebraic root until the original logarithm arguments are checked.

27

L Hospital rule after a form check

Principle

Certain 0/0 or ∞/∞ quotients can be evaluated through a quotient of derivatives when f and g are differentiable nearby, g′ stays nonzero there, and the derivative quotient has a limit or diverges appropriately. The rule does not say the derivative of a quotient equals f′/g′.

Why and when

Substitute first to verify 0/0 or ∞/∞. If another form appears, transform it into a quotient or use an earlier technique. Recheck the form before applying the rule again.

Worked solution

lim as x→0 of (e^x−1)/x is 0/0. Differentiating numerator and denominator separately yields lim e^x/1=1.

Additional worked example

Find lim as x→0 of sin(3x)/x.

It is 0/0; derivatives give lim 3cos(3x)/1=3.

Common trap. Do not apply the rule to 1/0 or to a quotient whose numerator and denominator do not form an indeterminate pair.

28

Newton iteration for approximate roots

Principle

The tangent at a current guess meets the x-axis at a revised guess. Repeating can converge rapidly near a simple root, but a zero derivative or poor starting point can fail.

Why and when

Choose a plausible starting value, compute f and f′ there, update, and check the residual |f(x_n)|. Stop when the residual or successive change meets the requested tolerance.

Worked solution

For f(x)=x²−2 and x₀=1.5, f(x₀)=0.25 and f′(x₀)=3. Thus x₁=1.5−0.25/3=17/12≈1.4167, closer to √2.

Additional worked example

Use one Newton step for f(x)=x²−3, starting at x₀=2.

f(2)=1 and f′(2)=4, so x₁=2−1/4=1.75.

Common trap. A small step is not enough evidence by itself; inspect the residual as well.

29

Antiderivatives and initial conditions

Principle

Antidifferentiation reverses a derivative on an interval. Every antiderivative differs by a constant. An initial condition selects one member of the family.

Why and when

Integrate each term, include C, use the initial condition, then differentiate the result to confirm the original rate.

Worked solution

If F′(x)=6x²−4 and F(1)=5, then F(x)=2x³−4x+C. Since 2−4+C=5, C=7.

Additional worked example

Find F when F′(x)=3x²+2x and F(0)=−1.

F(x)=x³+x²−1.

Common trap. The power rule for integration excludes exponent −1; that case gives ln|x|.

30

From finite sums to exact accumulation

Principle

A finite sum estimates accumulated quantity with rectangles of height times width. As widths shrink, the limiting sum gives the definite integral for an integrable function.

Why and when

Identify interval length, number of slices, width Δx, and sample point. Left and right sums can bracket an increasing function, but the integral is the exact limit, not either finite estimate.

Worked solution

For f(x)=x on [0,2] with two width-one slices, the left sum is 0+1=1 and the right sum is 1+2=3. The exact integral is 2.

Additional worked example

For f(x)=x² on [0,2], compute the two-rectangle left and right sums.

Width is 1. Left heights 0 and 1 give 1; right heights 1 and 4 give 5. The exact integral 8/3 lies between them.

Common trap. A rectangle estimate depends on the chosen sample point; keep the width factor.

31

The definite integral and signed area

Principle

The definite integral adds contributions with sign. A portion below the x-axis subtracts from a portion above. Geometric area instead adds positive magnitudes.

Why and when

Split an interval where f changes sign if the question asks for total area or distance. Reverse bounds to reverse integral sign; joining adjacent intervals adds their integrals.

Worked solution

For f(x)=x on [−1,1], equal triangles below and above the axis cancel, giving integral 0. The geometric area is 1/2+1/2=1.

Additional worked example

Evaluate ∫ from −1 to 2 of x dx and the total geometric area.

Signed integral [x²/2] from −1 to 2 is 3/2. Areas are 1/2 below plus 2 above, totaling 5/2.

Common trap. A signed net integral can be zero even when the region has positive area.

32

The fundamental theorem in both directions

Principle

Accumulation changes at the current rate. Conversely, an antiderivative evaluates net accumulation between bounds. This is the bridge between derivatives and integrals.

Why and when

For a variable upper bound g(x), evaluate the integrand at g(x) and multiply by g′(x). For a definite integral, find F with F′=f and compute upper minus lower.

Worked solution

For A(x)=∫₀^(x²) cos t dt, A′(x)=2x cos(x²). Also ∫₀²3x² dx=[x³]₀²=8.

Additional worked example

Differentiate ∫₁^(3x) √(1+t²) dt.

The derivative is 3√(1+9x²).

Common trap. A changing upper bound contributes its own derivative; omitting it loses the chain-rule factor.

33

Net change and basic integral rules

Principle

Accumulating a rate gives net change in the underlying quantity. Integrals of sums can be separated, and symmetry can shorten work on a centered interval.

Why and when

Identify the rate and its units. Integrate it over time for displacement or net production. For total distance or gross amount, account for sign changes instead of using net change alone.

Worked solution

If velocity is v(t)=2t−4 on [0,5], displacement is ∫₀⁵v dt=[t²−4t]₀⁵=5. The velocity changes sign at t=2; distance is 4+9=13.

Additional worked example

A tank receives water at r(t)=3t² liters/minute over 0≤t≤2. How much enters?

∫₀²3t² dt=[t³]₀²=8 liters.

Common trap. The units of an integrated rate are the original quantity, not quantity per time.

34

Substitution reverses the chain rule

Principle

A nested integrand becomes simpler when the inner expression is renamed and its derivative supplies the differential. For definite integrals, transform the bounds as well.

Why and when

Choose u, compute du, rewrite the entire integrand in u, change bounds if present, integrate, and either return to x or evaluate in u. Verify by differentiation.

Worked solution

∫₀¹2x(1+x²)³ dx: set u=1+x², du=2x dx. Bounds 0→1 and 1→2 yield ∫₁²u³ du=[u⁴/4]₁²=15/4.

Additional worked example

Evaluate ∫₀¹6x/(1+3x²) dx.

u=1+3x², du=6x dx; new bounds 1 and 4. Integral ∫₁⁴du/u=ln 4.

Common trap. Changing the integrand but retaining the old x-bounds mixes two variables.

35

Exponential and logarithmic antiderivatives

Principle

These patterns reverse the chain rule. A base e exponential integrates to itself after accounting for the inner rate; a reciprocal inner-rate pattern integrates to a logarithm.

Why and when

Look for the derivative of the exponent or denominator, adjusting a constant factor if necessary. Use ln|u| where u can be positive or negative on a valid interval.

Worked solution

∫[e^(2x)+3/x] dx=(1/2)e^(2x)+3ln|x|+C, on intervals avoiding zero.

Additional worked example

Evaluate ∫₀¹2e^(2x) dx.

An antiderivative is e^(2x); the result is e²−1.

Common trap. The factor 1/2 is needed in ∫e^(2x)dx because differentiating e^(2x) produces 2e^(2x).

36

Inverse trigonometric integral patterns

Principle

The derivatives of inverse trigonometric functions produce recognizable rational and radical integrands. The arcsine pattern requires |u|<1 for the derivative formula.

Why and when

First normalize any constant a and look for an inner substitution. Differentiate the proposed inverse function to confirm the coefficient and domain.

Worked solution

∫₀¹ 1/(1+x²) dx=[arctan x]₀¹=π/4. The denominator’s plus sign identifies inverse tangent.

Additional worked example

Find ∫ 2/(1+4x²) dx.

Let u=2x, du=2dx; the result is arctan(2x)+C.

Common trap. A 1−u² radical suggests arcsine; a 1+u² denominator suggests arctangent.

37

Area between two curves

Principle

A vertical slice has height equal to upper curve minus lower curve. Summing these heights across the interval gives area. Crossings require new upper-lower decisions.

Why and when

Find intersections, test which curve is higher on each interval, split where that ordering changes, and integrate a nonnegative height.

Worked solution

Between y=x and y=x² for 0≤x≤1, x≥x², so area is ∫₀¹(x−x²)dx=[x²/2−x³/3]₀¹=1/6.

Additional worked example

Find the enclosed area between y=2x and y=x².

They meet at x=0 and x=2. Area ∫₀²(2x−x²)dx=4/3.

Common trap. An unsigned area cannot be a negative result; recheck the curve order.

38

Volumes by slicing disks and washers

Principle

A solid can be built from thin cross sections. Rotation about an axis gives disks when there is no hole and washers when an inner boundary leaves a hole. The radii are distances to the axis.

Why and when

Draw one representative slice perpendicular to the rotation axis, identify outer radius R and inner radius r, square each separately, then integrate.

Worked solution

Rotate the region between y=2 and y=x on [0,2] about the x-axis. Outer radius is 2 and inner radius is x, so V=π∫₀²(4−x²)dx=16π/3.

Additional worked example

Rotate the region under y=x, 0≤x≤2, about the x-axis. Find the volume.

The inner radius is zero. V=π∫₀²x² dx=8π/3 cubic units.

Common trap. A washer area is π(R²−r²), not π(R−r)².

39

Cylindrical shells and method choice

Principle

A slice parallel to the axis of rotation forms a thin cylindrical shell. Its volume is circumference times height times thickness. Shells can avoid solving a curve for the other coordinate.

Why and when

Draw a representative strip. Radius is its distance to the axis; height is the region’s upper-lower span. Integrate over strip positions. Compare with disks or washers by which gives the simpler setup.

Worked solution

Rotate the region under y=x, 0≤x≤2, about the y-axis. A vertical strip has radius x and height x, so V=2π∫₀²x² dx=16π/3.

Additional worked example

Rotate the region under y=x², 0≤x≤1, about the y-axis. Use shells.

Radius x, height x²: V=2π∫₀¹x³ dx=π/2.

Common trap. A shell uses radius times height; squaring the height would produce a different volume.

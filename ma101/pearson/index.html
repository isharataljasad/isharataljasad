PEARSON / 01

Functions and mathematical language

01

Functions, domains, and piecewise rules

Idea

A function assigns exactly one output to every allowed input. Domain is the allowed input set; range is the outputs actually produced. A piecewise rule first asks which condition the input satisfies, then applies only that branch.

First move

For a formula, exclude zero denominators and negative radicands under even roots. For a piecewise graph, inspect the endpoint condition before evaluating. An open circle excludes its point; a filled circle includes it.

Worked reasoning

Let f(x)=√(x+2)/(x−1). The square root needs x≥−2 and the denominator needs x≠1, so the domain is [−2,1)∪(1,∞). For g(x)=x+1 when x<0 and x² when x≥0, g(0)=0, while the left-hand values approach 1.

Your turn

Find the domain of h(x)=√(5−x)/(x+2). Then give h(5).

Reveal answer and reasoning

The domain is (−∞,−2)∪(−2,5]. The endpoint 5 is allowed and h(5)=0. Exclude −2 even though the radicand is valid there.

If it went wrong. If you wrote x<5, you excluded a valid square-root endpoint. If you included −2, you overlooked the denominator.

02

Transformation, combination, and composition

Idea

Outside changes affect outputs; inside changes affect inputs. Addition and multiplication combine outputs at the same x. Composition sends the output of one function into the input of another, so its domain must satisfy both rules.

First move

To evaluate f(g(x)), compute g first, then apply f. For a graph transformation, test one landmark point rather than memorizing a sign slogan.

Worked reasoning

If f(x)=√x and g(x)=x−3, then (f∘g)(x)=√(x−3), whose domain is x≥3. In contrast, (g∘f)(x)=√x−3, whose domain is x≥0. The two compositions have different graphs and domains.

Your turn

For f(x)=1/x and g(x)=x+2, find (f∘g)(x) and its domain.

Reveal answer and reasoning

(f∘g)(x)=1/(x+2), with x≠−2. The restriction comes from the input reaching zero inside f.

If it went wrong. If you excluded x=0 instead, you checked f’s original input before composition rather than the actual input g(x).

03

Exponent rules before exponential models

Idea

Exponent rules operate on powers with the same nonzero base. A negative exponent is a reciprocal, and a fractional exponent is a root where the real-valued root exists. An exponential function keeps the base fixed and lets the exponent vary.

First move

Rewrite negative and fractional powers before simplifying. Match bases before combining exponents; addition of powered terms does not follow a product rule.

Worked reasoning

For x>0, x^(3/2)·x^(−1/2)=x^(1)=x. But x²+x³ cannot be replaced by x⁵; factoring gives x²(1+x). For 2^(x+1)=16, write 16=2⁴ and solve x+1=4, so x=3.

Your turn

Simplify (x³/x^(−2))^(1/5) for x>0.

Reveal answer and reasoning

Inside, x³/x^(−2)=x⁵. The fifth root gives x. The condition x>0 makes every fractional-power step unambiguous here.

If it went wrong. Subtracting exponents means 3−(−2)=5; subtracting 2 instead reverses the denominator’s negative sign.

04

Exponentials and logarithms as inverses

Idea

A logarithm asks which exponent produces a positive number. Products become sums of logarithms; powers become coefficients. A logarithm never accepts zero or a negative argument.

First move

Condense or expand only when all logarithm arguments are positive. When solving, isolate the logarithm or exponential, invert it, and check the original domain.

Worked reasoning

Solve ln(x−1)+ln(x+1)=ln 8. The domain requires x>1. Then ln(x²−1)=ln 8, so x²−1=8, giving x=3 or −3. Only x=3 survives the domain check.

Your turn

Solve 2 ln x=ln 9.

Reveal answer and reasoning

x>0 and ln(x²)=ln 9 imply x²=9; therefore x=3, not ±3.

If it went wrong. The logarithm domain removes the negative algebraic root; do not accept roots before checking the original equation.

05

Trigonometric models and inverse values

Idea

Radians connect angle to arc length and make calculus derivative formulas work without extra factors. Sine and cosine describe coordinates on the unit circle. Inverse trigonometric functions return a principal angle, not every angle with that value.

First move

Locate quadrant and reference angle before assigning signs. For an identity, replace one expression with an equivalent one on its valid domain; never cancel through a possible zero denominator.

Worked reasoning

If sin θ=3/5 and θ lies in quadrant II, then cos θ=−4/5 and tan θ=−3/4. The magnitude follows from the Pythagorean identity; quadrant II fixes the sign.

Your turn

Evaluate arcsin(−1/2), using its principal range.

Reveal answer and reasoning

−π/6, since arcsin returns an angle in [−π/2,π/2].

If it went wrong. A coterminal or quadrant-III angle may have the same sine but is outside arcsin’s output range.

06

Amplitude, period, and graph shifts

Idea

Amplitude measures vertical distance from the midline to a peak; period measures the horizontal length of one cycle. The midline is y=k. A phase shift moves landmarks horizontally, while a negative A reflects the sine wave about its midline.

First move

Read A, B, h, and k from a parenthesized argument. Mark one cycle using quarter-period steps; then apply the vertical scale and midline.

Worked reasoning

For y=2sin(3x)+1, amplitude is 2, midline is y=1, and period is 2π/3. Starting at x=0, one cycle reaches a maximum 3 at x=π/6 and a minimum −1 at x=π/2.

Your turn

For y=−3cos(2(x−π/4))+2, state amplitude, period, midline, and value at x=π/4.

Reveal answer and reasoning

Amplitude 3, period π, midline y=2, and y(π/4)=−3cos(0)+2=−1.

If it went wrong. The phase shift is π/4, not π/2: the argument already has the form 2(x−h).

PEARSON / 02

Limits and continuity

07

Approach from both sides

Idea

A limit is the value approached near c; it can differ from f(c). A two-sided finite limit exists only if both one-sided approaches agree. A hole changes the function value but need not change the limit.

First move

From a graph or piecewise rule, trace toward c from the left and right separately. State a two-sided limit only after comparing them.

Worked reasoning

Let f(x)=x+1 for x<2, and f(x)=x² for x≥2. The left limit at 2 is 3, the right limit is 4, and f(2)=4. Because 3≠4, the two-sided limit does not exist.

Your turn

Let g(x)=x² for x≠1 and g(1)=7. Find the limit as x approaches 1 and g(1).

Reveal answer and reasoning

The limit is 1, while g(1)=7. The isolated assigned value does not control nearby behavior.

If it went wrong. Substituting the point value for the limit confuses the output at c with the approach to c.

08

Algebraic limits and continuity

Idea

Direct substitution works when the expression is continuous at the point. An apparent 0/0 is a signal to simplify, not an answer. Continuity requires an existing limit, a defined point value, and equality between them.

First move

Substitute first. If 0/0 appears, factor, rationalize, or simplify on a punctured neighborhood. For a piecewise join, match the two side limits and the assigned value.

Worked reasoning

lim as x→3 of (x²−9)/(x−3) is not 0/0. For x≠3, factor to x+3; its limit is 6. Defining the missing value as 6 would make the function continuous at 3.

Your turn

Choose a so f(x)=ax+1 for x<2 and f(x)=x² for x≥2 is continuous at 2.

Reveal answer and reasoning

The right limit and point value are 4. Match 2a+1=4, so a=3/2.

If it went wrong. Matching only branch formulas is insufficient if the branch with equality assigns a different point value.

PEARSON / 03

Derivatives as changing rates

09

From secant to tangent

Idea

A derivative is the limit of average change over a shrinking interval. It is the tangent slope and the instantaneous rate, with output units divided by input units.

First move

When a problem asks for instantaneous slope or rate, compute f′ at the given input. A tangent line also needs the point (c,f(c)).

Worked reasoning

For f(x)=x², [f(c+h)−f(c)]/h=[(c+h)²−c²]/h=2c+h, so f′(c)=2c. At c=3, the tangent through (3,9) has slope 6: y−9=6(x−3).

Your turn

Find the tangent line to f(x)=x²+1 at x=2.

Reveal answer and reasoning

f(2)=5 and f′(2)=4, so y−5=4(x−2).

If it went wrong. A tangent slope alone is not the tangent line; include the function’s point value.

10

Read derivative graphs and corners

Idea

The sign of f′ reports increasing or decreasing behavior. A zero derivative gives a horizontal tangent but does not by itself prove an extremum. A corner or jump can prevent differentiability.

First move

Read the slope of f to infer f′, and check one-sided slopes at a corner. Differentiability implies continuity, but continuity alone does not imply differentiability.

Worked reasoning

For f(x)=|x|, the left slope at 0 is −1 and the right slope is +1. The function is continuous at 0, but f′(0) does not exist. For x³, f′(0)=0 yet there is no local extremum.

Your turn

For f(x)=x³−3x, identify intervals where f rises.

Reveal answer and reasoning

f′(x)=3x²−3=3(x−1)(x+1), positive on (−∞,−1) and (1,∞).

If it went wrong. A critical point is a candidate; classify it by sign change or another valid test.

PEARSON / 04

Differentiation tools

11

Basic and higher derivatives

Idea

Differentiate a sum term by term. The second derivative measures how the first derivative changes and later helps classify concavity and acceleration.

First move

Simplify a polynomial first, apply the power rule to each term, and keep the original variable. Differentiate again only when the question asks for acceleration, concavity, or higher-order change.

Worked reasoning

For f(x)=4x³−5x+7, f′(x)=12x²−5 and f″(x)=24x. At x=2 the slope is 43 and the second derivative is 48.

Your turn

Find the velocity and acceleration when s(t)=t³−6t²+2t.

Reveal answer and reasoning

v(t)=3t²−12t+2; a(t)=6t−12. Position, velocity, and acceleration have successive time derivatives.

If it went wrong. The derivative of a constant is zero; do not leave the +7 or its analogue in a derivative.

12

Products, quotients, and nested functions

Idea

A product has two changing factors, so both contribute. A nested function has an inner rate, which multiplies the outer rate. A quotient has a denominator squared.

First move

Mark the factors and inner expression before differentiating. Do not apply the power rule to an entire product unless it has first been algebraically expanded.

Worked reasoning

For y=x²(3x+1)⁴, treat x² and (3x+1)⁴ as factors. Then y′=2x(3x+1)⁴+12x²(3x+1)³. The 12 comes from 4 times the inner derivative 3.

Your turn

Differentiate y=(x²+1)/(x−1).

Reveal answer and reasoning

y′=[2x(x−1)−(x²+1)]/(x−1)²=(x²−2x−1)/(x−1)², for x≠1.

If it went wrong. If your quotient numerator has a plus sign between the two products, recheck the quotient rule.

13

Trigonometric derivatives

Idea

These rules assume radians. When a trigonometric expression contains an inner function, multiply by its derivative.

First move

Identify the outer trig function and its argument. Differentiate the argument last. Check signs, especially for cosine.

Worked reasoning

For y=sin(3x²), the outer derivative is cos(3x²) and the inner derivative is 6x, so y′=6x cos(3x²).

Your turn

Differentiate y=cos(2x−1)+tan x.

Reveal answer and reasoning

y′=−2 sin(2x−1)+sec²x.

If it went wrong. The factor 2 is required by the chain rule; cosine also supplies a minus sign.

PEARSON / 05

Applications of derivatives

14

Motion, velocity, and acceleration

Idea

Velocity has direction; speed is its magnitude. A particle moves right when velocity is positive and left when negative. Acceleration is change in velocity, not necessarily change in speed.

First move

Differentiate position, find where velocity changes sign, and interpret intervals. Total distance adds absolute changes in position; displacement is final minus initial position.

Worked reasoning

For s(t)=t²−4t on 0≤t≤5, v=2t−4 changes sign at t=2. Positions are s(0)=0, s(2)=−4, s(5)=5. Displacement is 5; total distance is 4+9=13.

Your turn

For s(t)=t²−2t on 0≤t≤3, find displacement and total distance.

Reveal answer and reasoning

Positions at t=0,1,3 are 0,−1,3. Displacement is 3 and total distance is 1+4=5.

If it went wrong. Using s(3)−s(0) for distance misses the reversal at t=1.

15

Implicit relations and related rates

Idea

When x and y are linked, differentiate every occurrence of y with the chain rule. For changing geometry, differentiate with respect to time before inserting a snapshot of the dimensions.

First move

Write a relation, label known rates with signs and units, differentiate, then substitute the instant’s values.

Worked reasoning

If x²+y²=25, then 2x+2yy′=0, so y′=−x/y where y≠0. For a circle A=πr², dA/dt=2πr dr/dt; at r=3 cm and dr/dt=2 cm/s, dA/dt=12π cm²/s.

Your turn

A sphere has V=(4/3)πr³. At r=2 cm and dr/dt=0.5 cm/s, how fast does volume change?

Reveal answer and reasoning

dV/dt=4πr² dr/dt=4π(4)(0.5)=8π cm³/s.

If it went wrong. Substituting r=2 before differentiating would turn a changing radius into a constant.

16

Linear estimates and differentials

Idea

Near a known input, the tangent line provides a local estimate. The differential dy=f′(x)dx estimates output change, with error usually growing as the step grows.

First move

Choose a convenient anchor a close to the target, calculate f(a) and f′(a), then multiply the derivative by the small input change.

Worked reasoning

Estimate √(4.1) using f(x)=√x at a=4. Since f(4)=2, f′(4)=1/4, and Δx=0.1, the estimate is 2+0.025=2.025.

Your turn

Estimate (8.12)^(1/3) using a=8.

Reveal answer and reasoning

f(8)=2, f′(8)=1/(3·8^(2/3))=1/12, Δx=0.12, so the estimate is 2.01.

If it went wrong. Use the derivative at the anchor and the difference from that anchor, not the target itself as Δx.

PEARSON / 06

Graphical decisions and optimization

17

Candidates for absolute extrema

Idea

On a closed interval, a continuous function reaches a largest and a smallest value. A critical point is where the derivative is zero or undefined; it is a candidate, not automatically an extremum.

First move

Differentiate, find interior critical points, evaluate the original function at each candidate and both endpoints, then compare values.

Worked reasoning

For f(x)=x³−3x on [−2,2], f′=3(x²−1), so check x=−2,−1,1,2. Their values are −2,2,−2,2. The absolute maximum is 2 and minimum is −2, each attained twice.

Your turn

Find the absolute maximum and minimum of f(x)=x²−4x+1 on [0,5].

Reveal answer and reasoning

f′=2x−4 vanishes at 2. Values f(0)=1, f(2)=−3, f(5)=6. Minimum −3 at 2; maximum 6 at 5.

If it went wrong. If you selected only x=2, you skipped endpoints, one of which gives the maximum.

18

Increasing, decreasing, and concavity

Idea

The first derivative controls direction; the second derivative controls how slope changes. A sign change in f′ can classify a local extremum. A sign change in f″ can identify an inflection point, provided the function is continuous there.

First move

Use sign intervals rather than isolated derivative values. Mark places where f′ or f″ is zero or undefined, test intervals, and verify that the claimed point belongs to the graph.

Worked reasoning

For f(x)=x³−3x, f′=3(x²−1): rise, fall, rise across −1 and 1. Thus a local maximum occurs at −1 and a local minimum at 1. Since f″=6x changes sign at 0, the graph has an inflection point at (0,0).

Your turn

For f(x)=x⁴, classify x=0 using f′ and f″.

Reveal answer and reasoning

f′=4x³ changes from negative to positive at 0, so 0 is a local minimum. f″=12x² is zero at 0 but stays nonnegative, so 0 is not an inflection point.

If it went wrong. A zero second derivative is only a candidate; without a concavity sign change there is no inflection.

19

Build and test an optimization model

Idea

An applied maximum or minimum needs a quantity to optimize and a constraint that removes extra variables. The feasible domain is part of the solution, and the final answer must use the asked-for units.

First move

Draw and label the situation, write the objective, use the constraint to reduce it to one variable, differentiate, compare candidate and boundary values, then interpret.

Worked reasoning

A rectangle with perimeter 20 has 2x+2y=20, so y=10−x for 0≤x≤10. Area A=x(10−x), with A′=10−2x. The maximum occurs at x=5, y=5, with area 25 square units; at the degenerate boundaries area is 0.

Your turn

A 24 m fence forms three sides of a rectangle against a wall. Find the maximum area.

Reveal answer and reasoning

Let the two widths be x and the fenced length y. Then 2x+y=24, A=x(24−2x), 0≤x≤12. A′=24−4x gives x=6, y=12, area 72 m².

If it went wrong. Using four fenced sides would impose the wrong constraint and answer.

PEARSON / 07

Exponential, logarithmic, and inverse derivatives

20

Exponential and logarithmic rates

Idea

The exponential e^x is its own derivative. A logarithm turns multiplication into addition and has a reciprocal rate. With a changing exponent or argument, the chain rule is still required.

First move

Identify the inner expression and its derivative. For ln|u|, work where u≠0; for ln u, require u>0.

Worked reasoning

For y=e^(2x) ln x on x>0, the product rule gives y′=2e^(2x)ln x+e^(2x)/x=e^(2x)(2ln x+1/x).

Your turn

Differentiate y=ln(x²+1).

Reveal answer and reasoning

y′=2x/(x²+1); the argument is positive for every real x.

If it went wrong. The derivative is not 1/(x²+1); the inner derivative 2x is essential.

21

Logarithmic differentiation

Idea

Taking a logarithm can turn variable powers and products into simpler sums. State the positive-domain assumption or use absolute values where appropriate.

First move

For y=[u(x)]^[v(x)] with u>0, write ln y=v ln u, differentiate both sides, then multiply by y.

Worked reasoning

For y=x^x on x>0, ln y=x ln x. Hence y′/y=ln x+1 and y′=x^x(ln x+1).

Your turn

Differentiate y=(x²+1)^x.

Reveal answer and reasoning

ln y=x ln(x²+1), so y′=(x²+1)^x[ln(x²+1)+2x²/(x²+1)].

If it went wrong. Treating x as a constant exponent would omit the ln(x²+1) term.

22

Inverse trigonometric derivatives

Idea

An inverse trigonometric derivative converts a rate of the input into a rate of angle. Its domain restrictions come from the inverse function and the displayed denominator.

First move

Use the correct inverse function rule and multiply by the derivative of the argument. For arcsin, note that the derivative is undefined at input ±1.

Worked reasoning

For y=arctan(2x), y′=2/(1+4x²). For y=arcsin(x²), y′=2x/√(1−x⁴), wherever |x|<1.

Your turn

Differentiate y=arctan(x³).

Reveal answer and reasoning

y′=3x²/(1+x⁶).

If it went wrong. Replacing arctan’s denominator with √(1−u²) confuses it with arcsin.

PEARSON / 08

Antiderivatives and initial data

23

Reverse a derivative

Idea

An antiderivative is a family of functions with the given derivative. All members differ by a constant on an interval. The exponent −1 is a special logarithmic case.

First move

Apply reverse rules term by term, retain +C, then differentiate your answer to verify it. Use initial data to determine C.

Worked reasoning

If F′(x)=6x²−4 and F(1)=5, then F(x)=2x³−4x+C. At x=1, 2−4+C=5, so C=7.

Your turn

Find F if F′(x)=3x²+2x and F(0)=−1.

Reveal answer and reasoning

F(x)=x³+x²−1; differentiating returns 3x²+2x.

If it went wrong. Without initial data, keep +C. With it, determine the unique member of the family.

Optional visual explanationNick Kaneko · Antiderivatives ↗

24

Core integral patterns

Idea

Integration reverses known derivative pairs. The absolute value in ln|x| allows either nonzero sign of x on an interval. Trigonometric antiderivatives still assume radians.

First move

Match the integrand to a derivative you know. Differentiate the proposed answer to check sign and coefficient.

Worked reasoning

∫[2x+cos x+1/x] dx=x²+sin x+ln|x|+C on any interval avoiding zero.

Your turn

Find ∫[3x²−sin x] dx.

Reveal answer and reasoning

x³+cos x+C, because the derivative of cos x is −sin x.

If it went wrong. A sign error in integrating −sin x is easy to catch by differentiation.

PEARSON / 09

Accumulation and definite integrals

25

Sums become accumulation

Idea

A Riemann sum adds height times width over many thin subintervals. The definite integral is signed accumulation; portions below the x-axis subtract rather than add.

First move

When given a sum, identify interval, width, and sample points. When asked for physical total distance or region area, use absolute values or split at crossings as needed.

Worked reasoning

For f(x)=x on [0,2], two equal left rectangles have heights 0 and 1, so their sum is 1. The right sum is 1+2=3. The exact integral is 2, between these estimates.

Your turn

Find the exact signed integral of f(x)=x on [−1,1], and its geometric area.

Reveal answer and reasoning

The signed integral is 0 because equal negative and positive triangles cancel. Geometric area is 1/2+1/2=1.

If it went wrong. Integral and geometric area differ when the function crosses the axis.

26

The two directions of the fundamental theorem

Idea

Accumulation has derivative equal to the current rate when f is continuous. Conversely, an antiderivative evaluates total signed accumulation between bounds.

First move

If the upper bound is a function g(x), multiply by g′(x). If evaluating an integral, find F and compute upper minus lower, with parentheses.

Worked reasoning

For A(x)=∫₁^(x²) cos t dt, A′(x)=cos(x²)·2x. Also ∫₀² 3x² dx=[x³]₀²=8.

Your turn

Find d/dx of ∫₀^(3x) √(1+t²) dt.

Reveal answer and reasoning

3√(1+9x²), from evaluating the integrand at 3x and multiplying by 3.

If it went wrong. Omitting the derivative of a variable upper bound loses the chain-rule factor.

Optional visual explanationNick Kaneko · Fundamental Theorem, Part 1 ↗

27

Average value and substitution

Idea

Average value is total accumulation divided by interval length. Substitution reverses the chain rule by replacing an inner function and its differential together.

First move

For a nested integrand, choose u as the inner expression. In a definite integral, change both bounds into u-values before integrating.

Worked reasoning

∫₀¹ 2x(1+x²)³ dx: let u=1+x², du=2x dx, and bounds become 1 and 2. Then ∫₁²u³ du=[u⁴/4]₁²=15/4.

Your turn

Find the average value of f(x)=x² on [0,2].

Reveal answer and reasoning

(1/2)∫₀²x² dx=(1/2)(8/3)=4/3.

If it went wrong. The integral alone is accumulated total. Divide by the interval length for the average.

PEARSON / 10

Regions and volumes

28

Area between graphs

Idea

The height of a vertical strip is upper curve minus lower curve. If curves cross inside the interval, the strip order changes and the area integral must be split.

First move

Find intersections, identify which curve is above on each interval, integrate the positive difference, then add the pieces.

Worked reasoning

Between y=x and y=x² on [0,1], x≥x², so A=∫₀¹(x−x²)dx=[x²/2−x³/3]₀¹=1/6.

Your turn

Find the area between y=2x and y=x² from their intersections.

Reveal answer and reasoning

Intersections are x=0 and x=2. Since 2x≥x² there, area is ∫₀²(2x−x²)dx=4/3.

If it went wrong. Integrating lower minus upper gives a negative signed value, not the requested area.

Disks and washers from cross sections

Idea

Rotation of a vertical region about a horizontal axis produces circular cross sections perpendicular to that axis. Radius is distance from the axis, so identify outer and inner boundaries before squaring.

First move

Draw one representative slice. If the region touches the axis, the inner radius is zero; otherwise subtract the hole.

Worked reasoning

Rotate the region under y=x, 0≤x≤2, about the x-axis. Its disk radius is x, so V=π∫₀²x² dx=8π/3 cubic units.

Your turn

Rotate the region between y=2 and y=x, 0≤x≤2, about the x-axis. Find the volume.

Reveal answer and reasoning

Outer radius 2, inner radius x. V=π∫₀²(4−x²)dx=16π/3.

If it went wrong. Squaring the difference (2−x)² describes the wrong cross-sectional area; use R²−r².

MA 101 · TOPIC 01

Limits

Find a limit before substituting into a broken expression.

Book →Pearson →Educator →

The idea

A limit describes nearby behaviour. A missing value at the point does not by itself prevent a limit. Factor or rationalise an indeterminate expression, cancel only for nearby allowed inputs, and then evaluate.

A first example

For (x² − 9)/(x − 3), factor the numerator. For x ≠ 3 the expression is x + 3, so its limit as x approaches 3 is 6. The original expression is still undefined at 3.

Engineering connection. A limiting model describes what a process approaches, even when an ideal endpoint is not directly measured.

What this explanation develops

  • the limit is calculated by direct substitution when it is legitimate, and it is known when it is not.
  • The limit of a fraction in which the substitution gives the form 0/0 is calculated by factoring or multiplying the conjugate.
  • Differentiate between the value of a function at a point and its limit at that point.
  • Rule that the limit does not exist if the two side limits are different.
  • Calculate limits at infinity and trigonometric limits, explain bounds, and interpret the definition of a limit.

Definitions & meaning

At infinity we compare the speed of growth of the boundaries. In breaking a polynomial, we divide the numerator and denominator by the highest power in the denominator. If the two degrees are equal, the ratio of the two main coefficients remains, and if the numerator is the lowest degree, the limit is zero. The highest degree in the numerator does not always give positive infinity: check the coefficient, sign, and point of approach. We do not replace the infinity symbol as if it were a number.

The base limit sin(x)/x=1 at x→0 assumes radians. Write sin(3x)/x=3 sin(3x)/(3x), the limit is 3., and by multiplying the conjugate, the limit of (1−cos x)/x² is one half. If a function is bounded between two functions with the same limit, it has that limit: From −x²≤x² sin(1/x)≤x² we deduce zero without the limit of sin(1/x) alone.

The divergence towards +∞ is not a true finished term. Near x=0, 1/x has two sides with different signs, while 1/x² is increasing infinitely from both sides. The terminus 1/x→0 at x→∞ gives a horizontal asymptote y=0; Another curve can intersect its asymptote, the line describing a distal behavior rather than a barrier.

Exact meaning: For every tolerance ε>0 around L we can choose a distance δ>0 around a, such that 0<|x−a|<δ ensures |f(x)−L|<ε. in f(x)=2x+1 at a=3, the error |f(x)−7|=2|x−3|; Choosing δ=ε/2 fulfills the condition. We do not need to know f(a) to set the adjacent values.

Limit
The limit of f(x) as x approaches a is L when f(x) approaches L as x approaches a from both sides, excluding x=a itself. We write lim(x→a) f(x)=L. The value f(a) may differ from L or may be undefined.
One-sided limit
A left-hand limit uses x<a; a right-hand limit uses x>a. A finite two-sided limit exists exactly when both one-sided limits exist and equal the same finite number.
Indeterminate form
The form 0/0 obtained by direct substitution is not a value. Different expressions with this form can have different limits. Simplify the expression or use another valid limit argument before deciding the result.
Direct substitution
Polynomials are continuous everywhere. A rational function is continuous wherever its denominator is nonzero. At such points its limit equals its value. Check the denominator and domain before substituting.

Formulas & conditions

Basic wording

lim(x→a) f(x) = L

It reads: The closer we bring x to a, the closer f(x) is to L.

Condition of existence

lim(x→a⁻) f = lim(x→a⁺) f ⟺ the limit is there

The difference between the two sides alone is sufficient to rule that there is no limit.

Direct substitution

lim(x→a) p(x) = p(a) for polynomial p

Polynomials do not create surprises, and substitution is always legitimate.

Why is it permissible to delete the factor even though it is equal to zero at the point

This is the question that many explanations skip. Deletion seems like a clear violation, so let's see why it's legitimate.

  1. Start at (x² − 9)/(x − 3) and factor the numerator to (x − 3)(x + 3).

    factoring reveals the common factor that creates zero in the denominator, so we know the source of the problem instead of confronting it.

  2. Note that the definition of limit speaks of x being close to 3 and x ≠ 3.

    This is the crucial point: the limit never asks about the value of the function at 3, but rather about its behavior around it.

  3. As long as x ≠ 3, x − 3 ≠ 0, and division by a non-zero number are allowed, eliminate the operator.

    Deletion is prohibited only at zero, and we have excluded zero by definition itself, so there is no objection left.

  4. The expression becomes x + 3 for every x ≠ 3, which is a polynomial, so substitute x = 3 to get 6.

    The two functions match in every point that concerns the limit, so their limit is the same, and it is permissible to substitute it for the second.

Worked examples

Always start with direct substitution. If a specific number comes out, you're done in one step. If the indeterminate form 0/0 comes out, this is not the end of the method, but rather its beginning: go to the factoring, If there is a square root, multiply by the conjugate. That's the whole decision tree in this lesson.

Example: 1 · is a fraction that gives 0/0, solved by factorization

Find lim(x→2) (x² − 4)/(x − 2).

  1. Substitute x = 2: for the numerator 4 − 4 = 0 and the denominator for 2 − 2 = 0, and the form is 0/0.

    We start with substitution to find out whether we need additional work at all. Indeterminate form 0/0 tells us we need it.

  2. Factor the numerator : x² − 4 = (x − 2)(x + 2).

    The appearance of 0 in both the numerator and denominator means that (x − 2) is a common factor, and the factoring shows it.

  3. Remove (x − 2) from the numerator and denominator, leaving x + 2 for every x ≠ 2.

    the limit considers x close to 2 and not equal to it, so the factor is non-zero and the deletion is legitimate.

  4. Substitute x = 2 into x + 2 and you get 4.

    x + 2 is a polynomial, and direct substitution is always legitimate.

Result: 4

Example: 2 · is a square root, solved by multiplying the conjugate

Find lim(x→0) (√(x + 4) − 2)/x.

  1. Substitute x = 0: for the numerator √4 − 2 = 0 and the denominator for 0, and the form is 0/0.

    The first step remains the same no matter how much the form of the expression changes: try the substitution first.

  2. factoring is not useful here because of the root, so multiply the numerator and denominator by the conjugate (√(x + 4) + 2).

    Multiplying the root by its conjugate removes the root via (a − b)(a + b) = a² − b², and multiplying by the same expression A numerator and a denominator do not change the value of the fraction.

  3. The numerator becomes (x + 4) − 4 = x, so the fraction becomes x / (x(√(x + 4) + 2)).

    Here the common factor x that was hidden behind the root appeared; This is the purpose of multiplying by the conjugate.

  4. Remove x, leaving 1/(√(x + 4) + 2), then replace x = 0 and you get 1/(2 + 2) = 0.25.

    Deletion is permissible because x ≠ 0 is inside the limit, and the denominator after substitution is not equal to zero, so substitution is permissible.

Result: 0.25

Confine oscillation

Calculate the limit of x² cos(1/x) at zero.

  1. −1≤cos(1/x)≤1

    The fluctuation is limited between these two numbers.

  2. −x²≤x² cos(1/x)≤x²

    We multiply by the non-negative x² so the inequalities are not reversed.

  3. The two outer limits are zero

    The squeeze theorem gives zero for the middle function.

Result: 0

Further worked applications

The first type: direct substitution

You know when the matter is finished in one step.

Find lim(x→4) (2x² − 3x + 1).

The expression is a polynomial, so direct substitution is : 2(4²) − 3(4) + 1 = 32 − 12 + 1 = 21. There is no need for factoring or any trick, because the substitution did not give an unspecified picture.

Result: 21 Number

Mode 2 · indeterminate form 0/0 is removed by factoring

Shift the expression before the substitution instead of stopping at 0/0.

Find lim(x→5) (x² − 25)/(x − 5).

Substitution gives 0/0. Factor the numerator : x² − 25 = (x − 5)(x + 5), then eliminate (x − 5) Because x ≠ 5 is inside the limit. x + 5 remains, and substituting in gives 5 + 5 = 10.

Result: 10 Number

The third type: value versus limit

Distinguish between what a function is equal to at a point and what it approaches around it.

A function defined as : f(x) = (x² − 4)/(x − 2) for each x ≠ 2 and f(2) = 7. Find lim(x→2) f(x).

the limit does not look at x = 2 at all, the value of f(2) = 7 does not enter the calculation. For every x ≠ 2 there is f(x) = (x − 2)(x + 2)/(x − 2) = x + 2, so the limit is 2 + 2 = 4. This is a function whose limit is 4 and whose value is 7 at the same point, which are two different things.

Result: 4 Number

Fourth style · One-sided limit

One aspect is examined carefully, and it is the basis for ruling that there is no limit.

Let f(x) = |x − 5|/(x − 5)., find the limit from the left as lim(x→5⁻) f(x).

To the left of 5, x < 5, so x − 5 is negative, and the absolute value of a negative number is negative: |x − 5| = −(x − 5)., the fraction becomes −(x − 5)/(x − 5) = −1 for every x < 5, and the limit is −1. On the right, the result is +1. The two sides are different, so the general limit at 5 does not exist.

Result: -1 Number

Type 5: A square root that requires a conjugate

Choose the right tool when factoring fails.

Find lim(x→0) (√(x + 9) − 3)/x. Write the result as a decimal number.

substitution gives 0/0, and the factoring is not useful due to the presence of the root. Multiply the numerator and denominator by the conjugate (√(x + 9) + 3), so the numerator becomes (x + 9) − 9 = x, and the fraction becomes x/(x(√(x + 9) + 3)). Remove x, leaving 1/(√(x + 9) + 3), and when x = 0 equals 1/(3 + 3) = 1/6 ≈ 0.1667.

Result: 0.16667 Number

Useful background

Difference of two squares factoring and triangular factoring

The difference between two squares : a² − b² = (a − b)(a + b). example : x² − 9 = (x − 3)(x + 3) because 9 = 3². The trinomial x² + bx + c is analyzed by looking for two numbers whose product is c and whose sum is b. Example: x² − 5x + 6 = (x − 2)(x − 3) because (−2)(−3) = 6 and (−2) + (−3) = −5.

cancellation in algebraic fractions, and when is it permissible?

It is permissible to reduce the common factor as long as it is not equal to zero. (x − 3)(x + 3) / (x − 3) = x + 3 True for all x except x = 3. The equality here is conditional, not absolute, which is why we write x ≠ 3 next to it. This is exactly what makes the cancellation legitimate inside the limit, as you will see in the derivation below.

MA 101 · TOPIC 01

Limits

Find a limit before substituting into a broken expression.

LearnCheckApply
THE IDEA

Understand the decision

A limit describes nearby behaviour. A missing value at the point does not by itself prevent a limit. Factor or rationalise an indeterminate expression, cancel only for nearby allowed inputs, and then evaluate.

Worked example

For (x² − 9)/(x − 3), factor the numerator. For x ≠ 3 the expression is x + 3, so its limit as x approaches 3 is 6. The original expression is still undefined at 3.

Engineering connection A limiting model describes what a process approaches, even when an ideal endpoint is not directly measured.

Investigating a limit

Meaning

A limit describes what outputs approach near an input, not necessarily the output at that input. Both one-sided approaches must agree for a finite two-sided limit.

Method

Use a graph to see approach direction and a table of nearby inputs on both sides to estimate. Then seek an algebraic argument: numerical evidence alone can mislead near a sharp feature. Separate a hole, jump, vertical asymptote, and oscillation.

Worked reasoning

For f(x)=(x²−4)/(x−2) with x≠2, nearby outputs approach 4 because f(x)=x+2 away from 2. The value f(2) remains undefined; the limit is 4.

Check yourself

If f(x)=−1 for x<0 and f(x)=2 for x≥0, what is lim as x→0 of f(x)?

Reveal answer and reasoning

The left limit is −1 and the right limit is 2; the two-sided limit does not exist.

Common error. A table with values only on one side cannot establish a two-sided limit.

Algebraic limit methods

Meaning

Direct substitution works when the expression remains continuous. An apparent 0/0 signals algebra to perform, not a numerical answer.

Method

Factor and cancel a common nonzero factor near the point; rationalize radicals; or divide by the dominant power for behavior at infinity. For a trigonometric limit, rewrite it to expose sin(u)/u and account for any scale factor. Use one-sided signs to analyze a denominator tending to zero without cancellation.

Worked reasoning

lim as x→3 of (x²−9)/(x−3) equals lim(x+3)=6 after factoring. In contrast, lim as x→∞ of (3x²−1)/(2x²+5)=3/2 after division by x².

Check yourself

Evaluate lim as x→0 of sin(5x)/x.

Reveal answer and reasoning

Rewrite as 5[sin(5x)/(5x)]; the inner ratio tends to 1, so the limit is 5.

Common error. Cancellation is legal for x near the target, not at the point where the original denominator is zero.

Approach from both sides

Idea

A limit is the value approached near c; it can differ from f(c). A two-sided finite limit exists only if both one-sided approaches agree. A hole changes the function value but need not change the limit.

First move

From a graph or piecewise rule, trace toward c from the left and right separately. State a two-sided limit only after comparing them.

Worked reasoning

Let f(x)=x+1 for x<2, and f(x)=x² for x≥2. The left limit at 2 is 3, the right limit is 4, and f(2)=4. Because 3≠4, the two-sided limit does not exist.

Your turn

Let g(x)=x² for x≠1 and g(1)=7. Find the limit as x approaches 1 and g(1).

Reveal answer and reasoning

The limit is 1, while g(1)=7. The isolated assigned value does not control nearby behavior.

If it went wrong. Substituting the point value for the limit confuses the output at c with the approach to c.

Algebraic limits and continuity

Idea

Direct substitution works when the expression is continuous at the point. An apparent 0/0 is a signal to simplify, not an answer. Continuity requires an existing limit, a defined point value, and equality between them.

First move

Substitute first. If 0/0 appears, factor, rationalize, or simplify on a punctured neighborhood. For a piecewise join, match the two side limits and the assigned value.

Worked reasoning

lim as x→3 of (x²−9)/(x−3) is not 0/0. For x≠3, factor to x+3; its limit is 6. Defining the missing value as 6 would make the function continuous at 3.

Your turn

Choose a so f(x)=ax+1 for x<2 and f(x)=x² for x≥2 is continuous at 2.

Reveal answer and reasoning

The right limit and point value are 4. Match 2a+1=4, so a=3/2.

If it went wrong. Matching only branch formulas is insufficient if the branch with equality assigns a different point value.

One-sided limits and failure to agree

Principle

A finite two-sided limit exists only if the left and right approaches settle at the same number. A point can have a different assigned value without changing that approach.

Why and when

Trace each side separately on a graph or in a piecewise rule. Distinguish a finite limit from unbounded behavior, a jump, and persistent oscillation.

Worked solution

Let f(x)=x+2 for x<1 and f(x)=x² for x≥1. The left limit is 3, the right limit is 1, and f(1)=1. Therefore the two-sided limit does not exist.

Try it

Let g(x)=x² for x≠2 and g(2)=9. Find the limit as x approaches 2 and g(2).

Reveal answer and reasoning

The limit is 4; the assigned value is 9. Changing one point does not alter the values around it.

Common trap. Substitution gives the point value only after continuity has been established.

Limit laws and algebraic repair

Principle

Limit laws permit arithmetic with finite limits. Direct substitution is valid for continuous expressions where defined. The indeterminate form 0/0 signals that more analysis is needed.

Why and when

Try substitution first. If 0/0 appears, factor, combine fractions, or rationalize. Simplify on x≠c before taking the limit; the function need not be defined at c.

Worked solution

lim as x→3 of (x²−9)/(x−3) equals lim(x+3)=6 because x²−9=(x−3)(x+3) away from 3.

Try it

Find lim as x→0 of [√(1+2x)−1]/x.

Reveal answer and reasoning

Multiply by the conjugate: 2/[√(1+2x)+1], which tends to 1.

Common trap. 0/0 is neither zero nor a limit value; it is a prompt to transform the expression.

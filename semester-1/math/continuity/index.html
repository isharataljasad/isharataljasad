THE IDEA

Understand the decision

Continuity at a point requires a defined value, an existing two-sided limit, and equality between them. The Intermediate Value Theorem needs continuity on the whole closed interval.

Worked example

If f(x) = (x² − 9)/(x − 3) away from 3, defining f(3) = 6 fills the removable gap. Giving it any other value leaves a discontinuity.

Engineering connection Before treating a measured trend as smooth, identify whether a model has a genuine jump or just a missing observation.

Approach 1 · Reference

Definitions and relationships

Continuity at a point
A function is continuous at a when f(a) is defined, lim(x→a) f(x) exists, and that limit equals f(a). Failure of any of these conditions gives a discontinuity at that point.
Removable discontinuity
A finite limit exists, but f(a) is missing or differs from the limit. Defining f(a) to equal that limit repairs continuity without changing the function at other points.
Jump discontinuity
Both one-sided limits are finite but unequal. Changing the value at a single point cannot make these limits equal.
Infinite discontinuity
The function becomes unbounded near the point. For example, 1/(x−5)² tends to +∞ from both sides of 5. For 1/(x−5), the signs differ on the two sides. Neither has a finite two-sided limit at 5.

The relationships you will use

  • f continuous at a ⟺ f(a) defined ∧ lim exists ∧ lim = f(a)The three conditionsRead them through a checklist: check them in order and stop at the first condition that occurs.
  • lim(x→a⁻) f ≠ lim(x→a⁺) f ⟹ jumpJump tagThe two sides exist and are different, and this is what distinguishes it from the infinite.
  • lim(x→a) f = L ≠ f(a) ⟹ removableRemovable tagLimit exists, the flaw is in the point alone.

Why do we need three conditions and two conditions are not enough?

The third condition may seem to be a repetition of the first two. Let us see an example in which each condition alone falls while the other two are met.

  1. Take f(x) = (x² − 4)/(x − 2) at x = 2: limit 4 exists, but f(2) is undefined.Why: Here the first condition alone fails. If we were satisfied with the existence of the limit, we would call this function continuous, but it is not.
  2. Take g(x) = |x − 2|/(x − 2) with g(2) = 0: The value is defined, but the limit does not exist.Why: Here the second condition alone fails. The presence of a value at a point says nothing about the behavior of the function around it.
  3. Take h(x) = (x² − 4)/(x − 2) for every x ≠ 2 with h(2) = 7: the value is defined and the limit is present, they are different.Why: Here the first two conditions were met and the third one failed. Therefore, equality must be explicitly stipulated.
  4. Combine the three: It is not enough for the two parties to exist, they must meet.Why: The meaning of continuity is that the path of the function reaches the same point without a jump or a hole. This is exactly what equality expresses in the third condition.

Approach 3 · Step-by-step teaching

From zero to solution

Check the conditions in order and do not jump. First: Is f(a) defined? Second: Calculate the limit from both sides. Third: Compare it with f(a). and stop at the first condition that falls, as it alone determines the type of discontinuity. As for “find the value of the constant” problems, they always apply the third condition: equate the limit with the value.

Example 1 · discontinuity rating

Rate the discontinuity f(x) = (x² − 1)/(x − 1) at x = 1.

  1. Check f(1): denominator 1 − 1 = 0, value is not defined. The first condition is invalid.Why: We started with the easiest one: substitution immediately detects whether a point is outside the domain.
  2. Calculate the limit : (x − 1)(x + 1)/(x − 1) = x + 1 for every x ≠ 1, so the limit is 2.Why: The failure of the first condition does not determine the type; The type is determined by the presence or absence of the limit.
  3. the limit exists and is finished, the discontinuity is removable.Why: It is enough to define f(1) = 2 for the function to become continuous, and the defect then lies in one point, not in the path.

Output: removable discontinuity, limit = 2

Example 2 · Find a constant that makes the function continuous

Find the a that makes f continuous at x = 2, where f(x) = ax + 1 of x ≤ 2, And f(x) = x² + 3 for x > 2.

  1. Calculate the limit from the right: lim(x→2⁺) (x² + 3) = 4 + 3 = 7.Why: To the right of 2 the second formula works, as it is the only one used in this limit.
  2. Calculate the limit from the left and the value of the function: both are a(2) + 1 = 2a + 1.Why: The condition x ≤ 2 includes the point itself, so the left branch gives the value and the left limit together.
  3. Equate both sides : 2a + 1 = 7, so a = 3.Why: continuity requires that the two sides meet at the same function value. Equality is the translation of the third condition.

Output: a = 3

Questions often left unexplained

Why do we say that the discontinuity is “removable” when the given function is actually discontinuous?

The label describes the possibility of reform, not the current state. The function as given is discontinuous, But a new function can be defined that matches it everywhere except that point, and is continuous. As for the jump and the infinite, this is not possible in them, no matter what you do with a single point.

Is every manifold function interrupted at the intersection point?

No. Bifurcation is a writing style, not a judgment on behavior. If the two sides and the value of the function are equal, then they are continuous. Example : f(x) = x for x < 0 and f(x) = x for x ≥ 0 is a fully connected hyperlinked function.

What is the relationship between connectivity and differentiability?

Every function is differentiable at a point at which it is continuous, and the opposite is not true. |x| is continuous at zero and cannot be differentiated there due to the acute angle. This will be detailed in the derivative lesson, which is outside the scope of this lesson.

Continuity and the intermediate value theorem

Meaning

Continuity at a means f(a) exists, the limit exists, and they agree. For a continuous function on [a,b], every value between f(a) and f(b) is attained somewhere inside.

Method

Check domain and one-sided behavior before invoking continuity. A hole can be repaired by assigning the limiting value; a jump generally cannot. For an existence question, identify a continuous interval and show the target lies between endpoint outputs.

Worked reasoning

Let f(x)=x³−x−1. It is continuous. Since f(1)=−1 and f(2)=5, some c in (1,2) satisfies f(c)=0, even without an explicit root.

Check yourself

Can the intermediate value theorem prove that x²−2 has a root between 1 and 2?

Reveal answer and reasoning

Yes. The polynomial is continuous, and its endpoint values are −1 and 2, so zero lies between them.

Common error. The theorem guarantees existence; it does not give a formula or prove uniqueness.

Algebraic limits and continuity

Idea

Direct substitution works when the expression is continuous at the point. An apparent 0/0 is a signal to simplify, not an answer. Continuity requires an existing limit, a defined point value, and equality between them.

First move

Substitute first. If 0/0 appears, factor, rationalize, or simplify on a punctured neighborhood. For a piecewise join, match the two side limits and the assigned value.

Worked reasoning

lim as x→3 of (x²−9)/(x−3) is not 0/0. For x≠3, factor to x+3; its limit is 6. Defining the missing value as 6 would make the function continuous at 3.

Your turn

Choose a so f(x)=ax+1 for x<2 and f(x)=x² for x≥2 is continuous at 2.

Reveal answer and reasoning

The right limit and point value are 4. Match 2a+1=4, so a=3/2.

If it went wrong. Matching only branch formulas is insufficient if the branch with equality assigns a different point value.

Continuity and guaranteed crossings

Principle

Continuity requires a defined point value, an existing two-sided limit, and agreement between them. On a closed interval, continuity also guarantees every intermediate output between the endpoint outputs occurs somewhere.

Why and when

At a piecewise join, compute both side limits and the assigned value. For an existence question, the intermediate value theorem requires continuity on the whole interval.

Worked solution

Let f(x)=ax+1 for x<2 and f(x)=x² for x≥2. Matching the left limit 2a+1 with f(2)=4 gives a=3/2.

Try it

Explain why x³+x−1 has a root between 0 and 1.

Reveal answer and reasoning

It is a continuous polynomial; values at 0 and 1 are −1 and 1. Since zero lies between those values, a root lies in (0,1).

Common trap. The theorem guarantees existence, not a formula for the root.

Practice

Question types

Each style examines something different. These selected patterns cover the lesson objectives, It is not all that can be asked about the topic.

Type 1 · A value that removes the discontinuity

The third condition applies: equal the value to the limit.

f(x) = (x² − 16)/(x − 4) function for both x ≠ 4 and f(4) = k. What value of k makes f continuous at x = 4?

Analyze and reduce : (x − 4)(x + 4)/(x − 4) = x + 4 for every x ≠ 4, so the limit is 4 + 4 = 8. The continuity requires k = 8.

The second type is measuring the jump

You calculate the two sides and compare them instead of just one.

For the function f(x) = |x − 2|/(x − 2) at x = 2:, calculate the limit from the right minus the limit from the left.

On the right x > 2 then |x − 2| = x − 2 and the ratio is +1. and on the left x < 2 The ratio is |x − 2| = −(x − 2), the ratio is −1., and the difference is 1 − (−1) = 2, which is the amount of the jump.

The third type is the position of infinite discontinuity

The absence of status alone is distinguished from the absence of both sides together.

At any value of x the function f(x) = (x + 2)/(x² − 9) has infinite discontinuity With a positive value of x?

The denominator is non-existent at x = 3 and x = −3, and the numerator is non-existent at either of them. They are both endless discontinuitys. The positive value is x = 3.

Fourth style: Checking the conditions

The limit is calculated at a location where both the numerator and denominator are non-existent.

For the function f(x) = (x − 3)/(x² − 9):, what is its limit at x → 3? Write the result as a decimal number.

Factor the denominator : x² − 9 = (x − 3)(x + 3), so the fraction is (x − 3)/((x − 3)(x + 3)) = 1/(x + 3) For each x ≠ 3. the substitution gives 1/6 ≈ 0.1667. the limit exists and the discontinuity at 3 is removable, not infinite.

Type 5 · Constant in a manifold function

You use the correct branch for each side before equating them.

Find a that makes the function continuous at x = 1, where f(x) = ax − 4 of x ≤ 1, And f(x) = x² + 2x − 1 for x > 1.

From the right : 1 + 2 − 1 = 2., from the left and from the value : a(1) − 4 = a − 4. The equality a − 4 = 2 gives a = 6.

Extrema and curve shape

The first derivative shows where a graph rises and falls; the second shows how it bends. Together they locate maxima, minima and inflection points.

← Rolle and Mean Value TheoremsMathematics contentsOptimization →

What this lesson explains

Before computers drew graphs, engineers sketched them from derivatives — and they still check computer output that way. More importantly, locating maxima and minima is the basis of optimization: the largest yield, the smallest cost, the strongest beam. This topic gives the tests; the next applies them.

Before you begin

Solving f′(x) = 0

Factor: 3x2 − 3 = 3(x − 1)(x + 1) = 0 gives x = ±1. A product is zero when one factor is zero.

Sign charts

Between consecutive zeros (and points of discontinuity) a continuous expression keeps one sign. Test one number in each interval.

Asymptotes

Vertical asymptote at x = a if f(x) → ±∞ as x → a. Horizontal asymptote y = L if f(x) → L as x → ±∞ (see Limits).

The idea, made visible

The sign of f′ tells you the direction of the graph: f′ > 0 on an interval means f is increasing there, f′ < 0 means decreasing. (This follows from the Mean Value Theorem.) The graph can only turn around where f′ = 0 or where f′ does not exist. Those inputs, inside the domain, are the critical points.

A critical point is only a candidate. At a local maximum the graph rises then falls, so f′ changes from + to −; at a local minimum f′ changes from − to +. If f′ does not change sign (as for x3 at 0), there is no extremum at all. This is the first-derivative test.

The sign of f″ tells you how the graph bends. f″ > 0: concave up, shaped like a cup, with slopes increasing. f″ < 0: concave down, shaped like a cap. A point where the concavity changes is an inflection point. The second-derivative test: if f′(c) = 0 and f″(c) > 0 the point is a local minimum (bottom of a cup); if f″(c) < 0 it is a local maximum. If f″(c) = 0 the test says nothing and you must use the first-derivative test.

On a closed interval [a, b], a continuous function always has an absolute maximum and an absolute minimum (the Extreme Value Theorem). They occur either at critical points or at the endpoints, so you find them by comparing the function values at all these candidates. Forgetting the endpoints is a classic error.

For a full sketch, also check the domain, intercepts, symmetry and asymptotes (the behaviour as x → ±∞ and near points where the function is undefined).

Key terms

Critical point
A number c in the domain of f where f′(c) = 0 or f′(c) does not exist.
Local maximum / minimum
f(c) is a local maximum if f(c) ≥ f(x) for all x near c (local minimum: ≤).
Absolute maximum / minimum
The largest / smallest value of f on the whole domain or interval being considered.
Concave up / down
On an interval, the graph lies above its tangent lines (up, f″ > 0) or below them (down, f″ < 0).
Inflection point
A point on the graph where the concavity changes. f″ = 0 or undefined there is necessary but not sufficient.

First-derivative test

f′: + → − at c ⇒ local max; − → + ⇒ local min; no sign change ⇒ neither

Conditions and limits: f continuous at c; c a critical point. Works even when f″(c) = 0 or f′(c) does not exist.

Second-derivative test

f′(c) = 0 and f″(c) > 0 ⇒ local min; f″(c) < 0 ⇒ local max

Conditions and limits: Needs f′(c) = 0 (not just “undefined”). If f″(c) = 0 the test is inconclusive.

Closed-interval method

absolute extrema on [a, b] ∈ { f(a), f(b), f(critical points in (a, b)) }

Conditions and limits: f continuous on the closed interval [a, b]. On open or infinite intervals an absolute extremum need not exist.

Concavity

f″ > 0 ⇒ concave up; f″ < 0 ⇒ concave down

Conditions and limits: On an interval. At an inflection point the sign of f″ changes.

Why it works: Why f″ = 0 does not always give an inflection point

Consider f(x) = x4.

  1. f″(x) = 12x2, so f″(0) = 0.

    A candidate for inflection.

  2. But f″(x) = 12x2 > 0 on both sides of 0.

    The concavity does not change: the graph is a cup on both sides.

  3. So (0, 0) is not an inflection point; it is actually a minimum.

    An inflection point needs a change of sign.

Always check the sign of f″ on both sides, just as the first-derivative test checks the sign of f′.

A first worked example

Curve-sketching and extrema procedure

  1. Domain, intercepts, symmetry, and asymptotes (limits at ±∞ and near excluded points).
  2. Compute f′; find critical points (f′ = 0 or undefined, inside the domain).
  3. Make a sign chart for f′: intervals of increase and decrease; classify each critical point (first-derivative test).
  4. Compute f″; make a sign chart: concavity and inflection points (where the sign changes).
  5. Plot the key points and join them with the shape the charts describe.
  6. For absolute extrema on [a, b]: evaluate f at the endpoints and at the critical points inside, and compare.

Locate a minimum

Problem. Find the minimum of f(x) = x2 − 6x.

  1. f′(x) = 2x − 6 = 0 ⇒ x = 3.

    The only critical point.

  2. f″(x) = 2 > 0.

    Concave up everywhere.

  3. f(3) = 9 − 18 = −9.

    Evaluate at the critical point.

Result: Minimum value −9 at x = 3 (the vertex).

What it means: Because the parabola is concave up everywhere, this local minimum is also the absolute minimum.

A different case

Absolute extrema on a closed interval

Problem. Find the absolute maximum and minimum of f(x) = x2 on [−1, 2].

  1. f′(x) = 2x = 0 ⇒ x = 0, which is in [−1, 2].

    Critical point inside.

  2. Candidates: f(−1) = 1, f(0) = 0, f(2) = 4.

    Endpoints and critical point.

  3. Compare.

    The largest and smallest of the candidate values.

Result: Absolute maximum 4 at x = 2; absolute minimum 0 at x = 0.

What it means: The maximum is at an endpoint, where f′ ≠ 0. Solving f′ = 0 alone would miss it.

More worked cases

Each case below uses a different skill. Every step and result is shown.

Full analysis of a cubic

Problem. Analyse f(x) = x3 − 3x: extrema, concavity and inflection.

  1. f′(x) = 3x2 − 3 = 3(x − 1)(x + 1): critical points x = −1, 1.

    Factor the derivative.

  2. Sign of f′: + for x < −1, − for −1 < x < 1, + for x > 1.

    Test x = −2, 0, 2.

  3. So local max at x = −1, f(−1) = 2; local min at x = 1, f(1) = −2.

    First-derivative test.

  4. f″(x) = 6x: negative for x < 0, positive for x > 0.

    Sign change at 0.

  5. Inflection point at (0, 0).

    Concavity changes there.

Result: Local max (−1, 2), local min (1, −2), inflection point (0, 0).

What it means: f is odd (f(−x) = −f(x)), so the graph is symmetric about the origin, which agrees with these results. There are no absolute extrema on the whole real line: f → ±∞.

A critical point that is not an extremum

Problem. Classify the critical point of f(x) = x3.

  1. f′(x) = 3x2 = 0 ⇒ x = 0.

    Critical point.

  2. f″(0) = 0: the second-derivative test is inconclusive.

    Cannot decide from f″.

  3. f′(x) = 3x2 > 0 on both sides of 0.

    No sign change of f′.

Result: x = 0 is neither a maximum nor a minimum (it is an inflection point with a horizontal tangent).

What it means: f′ = 0 identifies candidates; it does not by itself produce extrema.

Asymptotes in a sketch

Problem. Describe the asymptotes and monotonicity of f(x) = 2x / x − 1.

  1. Domain: x ≠ 1. Near x = 1 the numerator → 2 and the denominator → 0: vertical asymptote x = 1.

    Non-zero over zero.

  2. As x → ±∞, f(x) = 2 / 1 − 1/x → 2: horizontal asymptote y = 2.

    Divide by x.

  3. f′(x) = 2(x − 1) − 2x / (x − 1)2 = −2 / (x − 1)2 < 0.

    Quotient rule.

Result: Asymptotes x = 1 and y = 2; f is decreasing on (−∞, 1) and on (1, ∞); no critical points and no extrema.

What it means: Say “decreasing on each interval”, not “decreasing everywhere”: f(0) = 0 < f(2) = 4 across the asymptote.

Common misunderstandings

  • Misunderstanding: Every critical point is a maximum or minimum.

    Correct idea: Check the sign change: x³ has a critical point at 0 but no extremum.

  • Misunderstanding: Forgetting endpoints when finding absolute extrema on [a, b].

    Correct idea: Always evaluate f at a and b as well as at the critical points.

  • Misunderstanding: f″(c) = 0 means inflection point.

    Correct idea: The concavity must change; x⁴ has f″(0) = 0 but no inflection.

  • Misunderstanding: Reporting the x-value when the question asks for the maximum value.

    Correct idea: The maximum value is f(c); c is where it occurs. Give both.

  • Misunderstanding: Including points outside the domain as critical points.

    Correct idea: For 1/x, f′ is undefined at 0, but 0 is not in the domain, so it is not a critical point (still a place where the sign chart can change).
